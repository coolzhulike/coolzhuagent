# 浏览器关闭后重开导航衔接审查

0.2.54 正式安装实测仍白屏，不能以显式 show 或工程检查称验收通过。首次网址为空的 about:blank 属正常初始状态；首次输入地址并打开能正常显示，关闭后重开原地址却没有网页内容。

代码链路：关闭当前工具使用 disposeBrowser=true，native.close 将 current 清空并销毁原生资格。再次快捷打开只调用 native.resume；原实现仅处理 current 存在的隐藏视图，没有任何创建或导航请求。此时白色区域是 about:blank iframe，新增 show 不可能修复没有创建的视图。

修正在原生浏览器前端适配器内保留闭合目标的地址与上下文键；只在用户明确再次打开浏览器、且工程/聊天室上下文仍相同时，resume 重新走 navigate 创建新一代原生视图。日常隐藏/切换面板仍显示原驻留网页；跨工程或聊天室不得加载此前地址。地址不存入新的持久存储，不恢复任何输入票据、旧节点、旧执行任务，不变更权限。首次无地址仍空白。

风险控制：关闭仍同步清空 current、递增前端 generation，命令按原队列串行。重新导航消费 closedTarget；navigate 的请求代号、页面回调世代及后端资源绑定继续约束迟到状态。无需新增 provider、自动重试或默认网页。浏览器特定生命周期留在适配器，工作区面板只发显式打开动作。

实操验收：正常安装055；初始地址打开后关闭，再次更多→浏览器无需按打开网址/刷新即出现实际网页；真实Qwen新轮点击0→1；交付中关闭单独记录时点和真实释放，不以步骤间关闭替代。跨聊天室重开不得加载旧地址。Paint排在浏览器之后。
