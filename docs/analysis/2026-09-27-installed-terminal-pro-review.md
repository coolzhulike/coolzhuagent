## 失败与证据

0.2.18 安装版 Web SHA256 `581822BE7B8EAC97A9CC6AF1B64AEA5F5BA2369CE13445682FE0154D71CA1081`。初始 PowerShell 提示符可见；中文输出执行后，辅助功能文本有结果，但原生窗口可视区只见 `>>` 和空白，上滚也未能查看结果。整窗失败图及包身份见 [候选验收索引](../testing/release-0.2.18/functional-verification-and-test-design.md)。不能用 API 或旧源码页面通过覆盖此失败。

Sol 随后只读核对 1024 字符的原始 ConPTY 响应：四次 `ESC[H`，最后一次之后有命令、中文结果、PS 提示符及 `>>`，再有约 23 行 `ESC[K\r\n` 清屏填充。当前轻量投影把填充 CRLF 当新历史；每次 450ms 轮询又无条件滚到底，包括空输出，导致结果留在 DOM 却被推到视口之外，人工上滚也被抢回。未发现可确认遮盖文字的 CSS。原始记录不改写。

## Pro 意见与主会话采纳

- 将问题限定为输出到显示投影、滚动的缺陷，保留原始 PTY 输出、序列游标、重连和生命周期。
- 空轮询不能强制滚动；新输出到来时，只有用户原先贴近底部才跟随；上滚阅读不能被抢回。
- 正确处理本次必要的 CR/LF/CRLF、定位、清行/清屏，不直接丢弃真实输出，也不把所有空行一律删掉。
- 当前产品是持久命令终端，不为此次修复建设完整 VT 模拟器，不降级为一次性 shell，不用“命令完成”掩盖缺失内容。
- 新包必须重新验收：中文直接可见、长输出和人工滚动、中断后继续、刷新续接、关闭及真实副作用。源码验证不能代替安装版全窗截图。

主会话已授权 Sol Max 按以上边界窄修。其他 0.2.18 原生检查继续以提前发现问题；修复后另出候选版本，保留 0.2.18 失败和独立哈希。此审查不是四项任务总体通过意见。
