# 聊天裸网址的中文句读边界修复

060真实Browser Use回归的聊天消息为“http://127.0.0.1:63653/click.html，max_actions为数字1……”；前端富文本正则仅按空白和部分ASCII符号截止，导致链接href吞入整段中文。模型实际工具请求URL正确，不涉及Provider、工具执行或原生WebView导航能力，但用户点击该消息会打开错误地址，属于Agent前端入口缺陷。

采用最小修改：裸网址渲染和附件网址提取统一按常见中文句读及全角括号截止；未编码的逗号、句号等作为正文边界。其余正文仍由原有文本节点渲染，不吞字、不改聊天存储、不改变模型上下文。中文域名/路径和百分号编码保留；用户明确给出的Markdown目标仍走原有解析分支，可以表达包含句读的目标。此修改不保证任意自然语言无分隔粘连都可准确判定，不扩大为新的Markdown解析器。

风险检查：协议仅识别http/https；不新增注入HTML、远程脚本或直接执行接口；既有内容预览和原生浏览器接线复用。没有改按钮视觉或添加前端调试信息。源级小范围验证后必须离线build，并在新正式安装版点击原有真实消息的链接，检查右栏URL与页面；不能仅凭正则验证称软件通过。

061包将包含本修复，060历史报告及失败链接保持原事实，不回填。本轮Pro补审按用户决定暂停，主会话完成此窄审。
