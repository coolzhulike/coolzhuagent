# 内置浏览器“当前页面”无URL请求修补方案（2026-10-07）

088正式验收的首个候选请求未填写target.url，认证宿主已返回可见页面，但验收函数把None与实际URL比较后拒绝，零输入。普通用户说“操作当前右栏网页”也会触发此缺口。明确URL路径和087/088已交付证据保持原范围；本修补另行验证。

## 决策与职责

只在原生浏览器适配器内保存本次实例第一份已加载认证观察的来源：host、工程/聊天室/面板资源、URL、文档token。来源一次绑定、不因后续手动切页重新绑定，也不读取网页文字/历史对话猜地址。加载控制态不作已加载来源。

验收模块在target.url确实缺省时使用该宿主来源作为比较基准；直接观察必须仍属于相同资源/URL/文档，输入导致的转场或显式导航继续走既有已结算输入/导航回执链。请求明确提供URL时仍严格按该URL，不允许当前页来源覆盖。来源只解决选择当前页面，不新增工具、权限或投递入口。

原节点预检、一次性票据、owner命中、二次状态检查、取消/释放和验收前后新鲜度保持。新鲜度采样的独立适配器只核当前真实事实，不允许把它的新初始来源覆盖主执行实例已绑定来源。宿主来源不从模型动作参数接受；失败不能自动补发。

## 风险与验收

缺省目标若每次随当前页漂移，会误操作切换后的面板，因此首份来源须不可改。错误URL仍应在观察阶段拒绝，不能借缺省修补放宽明确目标。手动换页/面板、关闭、规划期文档变更必须继续拒绝旧引用；点击正常导致URL变化仍按已结算回执核验。

代码仅补必要的有URL/无URL及来源替换边界检查，实际offline build后以原SWE-2-medium/唯一island-kayak真实网页验证无URL点击/滚动正向、明确错误URL零输入和规划期变化零输入，配截图、真实事件及原失败记录。候选通过后再单独冻结、打包、安装复验，不把088六轮当作本项完成。Paint不再测试，微信不动，Opus暂停，主会话独立执行。
