# Browser 读取结束时资源归属复核

当前native_browser_devtools的回调已优先识别资源/URL变化，但UI派发失败直接native_browser_unavailable，CoreWebView2/固定读取即时失败直接native_observation_failed，接收等待超时/取消直接对应通用错误。已知关闭或导航可能因错误先返回而被掩盖；回调成功到异步消费之间的资源变化也没有再次复核。此为代码审查发现，尚未实机复现，不能把严格时序缺口写成已通过。

采用同一个私有资源/URL判断，复用既有PanelResource与网页真实URL。UI派发失败返回前检查；callback沿用此判断；等待结果结算后再检查，然后才返回原成功/错误。资源已变化优先native_browser_resource_changed，未变化时保留原HRESULT分类、超时或取消。读取仍2秒上限、不扩大外层5秒、无重试/暂停/私有命令/新锁/队列，固定只读方法和目标附着归属保持。

风险与界限：最终检查不能撤回先前已投递输入；只描述本次读取已失效，输入事实由原逐步回执表达。普通导航不是nativeTarget替换；同URL文档ABA仍由文档/节点世代后续验证，不宣称URL能完整识别文档。既有callback与新的消费前检查之间仍可能发生后续变化，后续派发入口必须沿用现有资格验证。本改动只补原因与成功回执的结束归属，不声称严格down/up中间窗口已验收。

验证先独立壳offline build及既有回归。正常正式/候选界面和同一真实SWE/原island，普通网页长任务可作浏览器负载，不代替模型/插件，也不能暂停产品或注入私有CDP。正常关闭/导航必须发生在真实登记到读取结束之间，否则只记未命中；截图及逐步回执共同确认零新文档输入/旧输入释放。具体即时HRESULT与资源竞争若不可真实触发，保留开放，不写成全通过。
