# 工具参数诊断投影（候选，正式120不包含）

源码审查确认：MCP/部分DSH路径隐藏参数，但普通工具、并行调用及registry默认参数仍通过diag直接写入人读诊断；model_diagnostic_note也重复复制原参数。未知插件可在任意字段传入正文、路径或凭据，按字段名枚举无法覆盖。

用独立无状态tool_diagnostics::input_shape统一五个诊断入口。仅记录JSON根类型和对象字段数/数组长度，不输出字段名、值、内容长度或哈希；不遍历嵌套内容。所有provider同一规则。真实调用、权威参数持久化、工具消息、执行器/权限/取消/预算不改变。不是新的过滤器或审批，执行参数不做替换。

必要回归验证同类型/数量的不同键、值、嵌套秘密产生相同诊断，原离线build和Web回归实际退出。下一次正式真实长程工具调用同时核对输入事实正常且新增诊断不含目标输入正文。此候选不声称完整6.1：其它错误文本、导出、历史日志、全局配额仍需独立处理。旧日志不批量删除，不宣称自动去除已有内容。
