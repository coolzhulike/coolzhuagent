# 独立进程子页面编辑、按键与滚动实施方案（2026-10-06）

0.2.85已正式完成跨来源独立子按钮和轴缩放、父遮挡、规划期间子导航拒绝。本阶段补齐跨进程子页面的基础输入，不把已有按钮证据当作编辑或滚动通过。主会话独立实施和测试，使用SWE-2-medium，Opus暂停，微信不改。用户已清除Devin云端会话；旧veiled-anise仅为历史证据，后续重新绑定一个云端会话，聊天、内部规划和验收均复用它，详见[单会话实施方案](devin-single-session-next-plan.md)。

## 现有缺口与分工

节点与文档身份、owner链、目标会话和点击几何已由各自小模块管理。编辑器的DOM.resolveNode、Runtime.callFunctionOn及Runtime.releaseObject仍走顶层会话；跨进程节点不可能用顶层解释其backend节点或objectId，不能只删除能力拒绝。滚动还用顶层的owner中心及命中，独立子目标需要先在自身布局视口选择局部点，再沿原owner链换算到顶层。

固定devtools枚举统一派发到所属会话；调用方不能提供任意方法或脚本。编辑器解析、短期原值/选区和焦点读取、最后输入前的回调与对象释放始终绑定同一会话，失败不回退顶层。文字和页面单键仍由原顶层WebView发出真实输入，由浏览器路由到实际焦点；不自动聚焦、不写DOM值、不增加系统快捷键。原资源身份、文档预检、一次性许可、取消、过期和按键释放沿用。

几何模块复用已有owner映射，增加目标根布局视口中心入口。滚动模块按实际所属会话读取文档滚动根、真实滚动位置与余量；同目标内嵌子Frame用自身owner中心，独立目标根用自身布局视口中心。局部命中须属于选定子文档，父链须命中实际owner。预检重读几何、文档和滚动位置，不自动滚动；距离限制在当前子文档余量，到底/到顶不把输入转给父页。

## 验收顺序和风险

1. 候选离线真实构建及既有桌面壳回归通过后，使用原SWE在127.0.0.1父页/localhost子页中点击、输入唯一文字，并按Enter触发真实子表单。父输入和父提交保持0，事件必须可信，逐动作回执与原图对应。
2. 单独完成父输入回归，确认增加子会话路由不会影响顶层。子滚动向下、向上、到底零投递与父页不滚动分别记录，不能用页面初始位置代替真实滚动。
3. 正常页面切换在实际规划期间改变子焦点或子文档：旧目标零文字/按键/滚动输入。没有命中所需时序就保留为诊断，不追认通过，不人为延迟模型或修改回复。
4. 原始失败与成功均归档，候选不算正式。正常重新打包、安装、逐文件核验后，再做正式真实模型实操并恢复日常工作区。

浏览器协议ACK只证明接收，不代表页面效果或模型目标达成。目标附着/焦点变化、导航、父覆盖、子文档边缘以及布局映射是本阶段关注点。旋转/透视、横向RTL、严格按住新导航及面板关闭竞态继续独立列项，不以本阶段通过外推全部HTML。

## 官方接口依据

[WebView2 ICoreWebView2_11](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_11#calldevtoolsprotocolmethodforsession)提供对已附着session的固定协议调用。[Chromium Input](https://chromedevtools.github.io/devtools-protocol/tot/Input/)说明insertText为真实文字输入、dispatchKeyEvent为页面键事件。接口支持会话读取和页面输入；是否正确到达独立子页面仍须本机WebView2与真实SWE验证，不能仅凭文档认定通过。
