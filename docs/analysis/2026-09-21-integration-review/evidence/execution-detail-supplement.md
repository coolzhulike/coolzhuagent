## 执行管理、证据与发行细则（主代理细化草案）

本节是在本机源码审计基础上拟定的实施细节，不能标成 GPT6 Pro 原文或已经实施。最终阶段编号以04计划为准。

### 单个工作包和PR的统一交接卡

每个工作包必须附以下字段，其他模型可直接据此建立任务和测试。缺少前置或证据只能记未执行/阻断，不能填通过。

| 字段 | 填写要求 |
|---|---|
| 身份 | WBS-ID、关联缺陷/功能ID、源码commit或无Git时源码清单哈希、前置PR |
| 目标 | 用户可见的前后行为；明确保护的现有功能 |
| 改动范围 | 指定crate/文件所有者、可改入口、共享文件禁改范围 |
| 契约 | 输入输出、错误、终态、权限、取消、超时、owner、usage归属；拟议字段不能写成现存字段 |
| 数据 | schema/配置版本、兼容读写、旧数据处理、备份身份和迁移日志；无迁移写无 |
| 验证 | 对应06案例ID、实际命令、环境/fixture、预期、结果、原始证据位置、未知项 |
| 退出 | 量化或确定性门槛；不以代码编译/工具返回成功代替业务目标 |
| 回退 | 性能开关、停止新任务、匹配二进制/库备份、执行恢复者；不可关闭可靠性不变量 |
| 发布 | 源码、安装包/二进制/静态资源hash关联，安装前后数据核对，变更报告 |

小型PR只交相关字段和测试，不为凑齐模板创建重复测试。接口或数据变化必须有契约测试；真实键鼠、权限、迁移必须有相应故障证据。

### 可并行与必须串行的边界

允许并行：脱敏fixture/测试靶场、独立UI模块原型、官方资料和许可证清单、已冻结契约下的Windows后端适配、文档与非写入投影。每项明确负责人和文件所有者。

必须串行：公共动作结果枚举、运行身份、事件序号与schema迁移、配置优先级、生产工具权限解析、主循环执行权切换。一个PR合入契约后，其他分支才能基于该版本修改。禁止两个代理同时编辑巨型main.rs的同一职责段；由集成负责人只做薄层接线，功能代码先在独立模块完成。不要一次移动全部87k行后再修行为。

副作用并行还有运行约束：一个真实turn只有一个执行owner；同一交互桌面的键鼠只能有一个输入owner；两个独立工作区文件写入也需遵循各自任务授权与冲突管理。影子运行只能处理录制输入并比较请求/投影，不能调用真实工具执行器。

### 数据迁移的实际演练步骤

1. 选择脱敏副本，记录JSON、SQLite及附件目录的身份、大小、schema版本、会话/消息/配置计数；备份方式必须保证SQLite与WAL一致，不能在活跃写入时随手复制主文件。
2. 对副本执行迁移；旧秘密引用与百炼Base URL进行语义比对，API Key不打印、不重新录入、不以空值覆盖。找不到原秘密来源就标记需用户补充，不能生成虚假值。
3. 执行旧消息打开、检索、模型配置解析、附件引用、Goal恢复和工具审计查询。旧记录缺失usage或精确动作事实时保持unknown/imported标识。
4. 在事务和事件广播关键点注入崩溃；恢复后不丢已提交记录，不重复外部副作用，不生成第二个终态；搜索等派生索引可重建。
5. 演练更高schema被旧程序拒绝写入；退回时先停止写者，按兼容矩阵选择兼容旧代码或匹配的数据备份。恢复不是随意覆盖正在运行的用户库。
6. 验收后才在安装流程中启用真实数据迁移；安装失败保留原数据与可执行恢复指引。生产迁移的最终范围在对应PR中审阅。

### Paint分层实验登记

| 层次 | 初态与目标 | 必须保留的证据 | 不能作为通过依据 |
|---|---|---|---|
| P-A 输入契约 | 可控靶场；down前/后、路径中、释放、后截图处注入故障 | action_id、发送事实、最后确认点、释放结果、错误子类、租约生命周期 | mock通过就声称Paint可用 |
| P-B 最低真实闭环 | 新空白Paint，固定窗口/DPI；选工具并确认；画一条短线和矩形 | 起点/中间/终点图、绘图区ROI、实际工具状态、真实输入记录、目标变化 | 工具栏变了、光标动了或API返回ok |
| P-C 复杂任务归因 | 相同Qwen配置和初态下低质量海绵宝宝；只改变一个Agent因素 | 每组预注册样本、模型参数/提示版本、全流程证据、已知/未知usage、独立验收 | 脚本生成图片、上一轮已有图、只挑成功轮、临时降低标准 |

P-B先稳定通过，P-C才具备归因基础。若B在确定性指令下失败，优先修宿主接口；B通过而模型选点错误仍存在，再比较反馈/UIA/ROI；Agent不变量通过且模型持续输出错误计划时，将剩余项标为模型限制。不是要求画作审美质量达标，而是要求目标在真实画布有可核实的新内容。

原始03中的10次规划、2K新增反馈、≤1像素、≤5%误拒、≥30%token下降与1秒释放是实验候选。不得未测即写发布承诺。预注册时依据设备、模型、网络与测试集说明样本量和误差；确定性的权限、身份、独占、无盲重放、无虚假成功在该测试集内要求零违例。有限样本零违例不能推论现实世界永不失败。

### 长程任务、浏览器与真实模型的补充门禁

- Qwen基础会话：saved→resolved→wire检查，模型ID保持qwen3.8-flash，保留原Base URL/密钥引用；供应商参数文档在实施日复核，不能把当前计划冻结为永远正确的模型目录。
- 多模态：可识图模型收到原图协议块，纯文本会话收到默认视觉会话的有来源描述；引用错图、附件不可读、视觉路由失败均明确错误，不静默猜图。Agnes是当前配置名而非代码常量。
- 长程文件任务：在独立测试工程生成HTML/SVG鹈鹕骑自行车动画；查文件实际存在、浏览器运行和动画帧变化、需求清单覆盖、工具调用与终态。中途取消/重启后由授权恢复流程决定后续，不把生成的摘要当文件。此测试不替代Paint手工UI输入。
- 浏览器：在本地受控页面做读取、填写、提交并验证结果，标签页owner和导航/上传失败分别报告；DOM交互成功不能代替Windows原生CU成功。
- 生产端等价：同一fixture分别从Web、CLI、子Agent入口运行，检查权限、工具配对、取消、身份、usage与终态；Web仍需真实增量流，不能用CLI一次返回Vec伪装流式等价。

### 统一参数页与视觉工作范围

参数页补功能维度：连接协议/endpoint；模型ID与能力覆盖；思考模式/层级与供应商映射；采样/输出/上下文限制；工具调用能力；图片输入能力；默认视觉会话引用；请求超时/重试；配置来源和字段验证。能力未知允许用户显式配置并测试，不能靠模型名硬猜；不支持的参数在保存和发送前解释，不能悄悄传空值或吞掉。音频/视频为独立能力与后续路径，不由“多模态”总开关自动宣称支持。

视觉改造候选只先出设计：保留玉石色控件与icon、武侠竹林背景；内容区使用独立对比层；顶部Agent/工程/聊天室单行下拉；左快捷轨点击打开右扩展页；运行思考临时展示，完成后收起思考；工具放状态区；索引/搜索/耗时/token在既有入口上改善。无操作的icon隐藏或明确禁用原因，不新增装饰性伪按钮。

评审材料包括当前问题编号、低高度/常规/高DPI布局、键盘焦点路径、正文/次要文字对比测量和2–3个方案。方案可用imagegen生成视觉参考，但参考图不是已实现页面；用户选定后再做范围明确的UI PR。React与否须由独立资源构建、模块依赖和可维护性POC决定，不绑定视觉方案。

### 发行与回退检查单

1. 受影响crate离线实际构建，相关契约/集成测试通过；记录未执行和ignored原因。静态前端内联变更必须重新构建web-console，不能只刷新浏览器。
2. 当前源码commit、打包配置、MSI、安装后的web-console/桌面入口和静态资源具有可对应的版本/hash；安全扫描和签名有实际结果时才写已通过。
3. 使用测试数据完成首次安装、覆盖升级、卸载保留策略和迁移回退；再核真实用户数据保留（密钥不输出）。安装程序退出0与真实桌面启动分开验收。
4. 安装版进行可见前端、Qwen基本会话、多模态两路、工具状态/搜索/用量和相关CU最低闭环；如环境不允许其中一项，报告阻断项，不以后台HTTP冒烟替代。
5. 发布报告给每个功能ID写变更、前后行为、接口/配置/schema变化、复现步骤、实际测试、证据、局限、回滚。代码PR附报告和安装产物身份；不把本轮审查当成已经发布下一版。

首次发行仅交付通过门禁的已选择工作包。P4可选扩展、全部23领域深化和全面UI改造不用捆绑同一次发版。若输入可靠性不变量失败，停止CU能力发布；其他独立通过且不依赖失败部分的功能可单独评审。
