## 尚未覆盖完整的范围

- 51个测试族不等于完整产品回归集，不替代原有测试；任何字段/接口或状态机变化须追加真实输入输出样例、兼容负例和故障点。
- Windows沙箱与GUI输入隔离需要选定实现后建立威胁模型。几个路径与进程测试不能证明安全边界完备，也不能控制产品外的全权限程序。
- MCP四transport的精确名称、真实外部provider、语言服务器/PTY兼容、语音硬件与原生壳需逐项环境清单；无凭据/外部实现时单列未验。
- Pro建议的大历史、争用、Paint样本数与性能门槛须绑定参考环境、采样方法和单独成本计划，不能从“设计文档已写”推导通过。
- 主计划04是最终执行依赖与字段语义的依据；本文件只作测试映射，不覆盖原文审查记录，也不重新定义预算。
