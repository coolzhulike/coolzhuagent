## 实操发现的导航判定缺口

候选SWE首轮明确给出合法computer_use_perform参数，objective要求导航到B，constraints禁止点击、输入、按键和滚动；旧本轮边界模块仅识别少量自然语言的“允许导航”句式，误降为只读。结果为native_browser_verification_failed、attempts=0，页面仍为A，不能计通过。

修复留在ComputerUseTurnScope：仅当本轮已合法解析的显式Browser参数目标明确包含“导航到”或“navigate to”时，保留导航交互；绝对零输入与禁止导航仍优先。不从历史或模型参数扩大权限，不改变执行器和聊天室权限。补到既有导航边界回归，使用本轮失败样式与明确禁令反例；失败请求不复活，新请求单独记录。
