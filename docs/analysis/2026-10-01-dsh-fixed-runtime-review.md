2026-10-01，主会话独立实施，承接[固定远程源码下载审查](2026-10-01-dsh-remote-download-review.md)。这是未发布工程后续；正式0.2.63 MSI不包含本轮代码或运行资源，插件市场仍未完成真实Qwen验收。

## 风险与取舍

现有源码快照明确排除node_modules与第三方二进制。直接把开发机全局Node/SDK复制进包，不能证明正式程序用的运行资源来自本次审查。保留现有源码、构建输入、载荷三个身份口径，另外登记固定第三方资源和完整文件信任表，清理包根之前核验，复制之前及之后再次核验。必需资源缺失直接拒绝，不以optional跳过，不在打包阶段下载或改写锁。

本轮固定已用于实际宿主工程核验的Node24.15.0 Windows x64发行包。按[Node官方摘要](https://nodejs.org/download/release/v24.15.0/SHASUMS256.txt)核验发行ZIP及其中node.exe；ZIP摘要cc5149eabd53779ce1e7bdc5401643622d0c7e6800ade18928a767e940bb0e62，node.exe摘要3331e1ffe19874215472217c5e94f5a0c6d8e18c4ac7111d3937aa0ad5e9b4a5。保留官方完整LICENSE，不携带npm、安装器、示例或用户配置。

SDK来源只接受现有package-lock.json中的17个固定官方npm归档，逐个核验SHA512完整性、包名/版本，再有界展开全部普通文件。禁止重定向、链接、路径逃逸、Windows别名、重复文件与超限归档。准备脚本不运行npm、安装/构建脚本或第三方插件入口。版本变化需审查并修改信任表，普通准备操作不能自动覆盖既有锁。

运行时信任表进入版本管理和Core编译期；实际资源目录及SDK文件仍在tmp，不能充当第一方源码。第三方文件逐一核对path/size/SHA256并核验完整文件集合；五个第一方宿主文件按本次冻结源码及编译期内容核对。不能以“SDK锁文件摘要一致”替代真实SDK字节核验。正式定位仅为可执行文件旁bin/dsh-runtime，没有全局PATH、工程node_modules或用户缓存兜底。

文件身份与受控进程不等于OS沙箱或第三方代码批准。仍需P3启用资格、冻结schema、真实父轮身份、权限与共享预算接线。每次接纳/执行应重新核验，旧核验结果不得作为新调用资格；Core文件核验检查既有ExecutionControl的取消与截止，不重置父任务预算。本轮没有声称文件核验消除了操作系统并发写入的所有竞态。

## 模块职责

| 位置 | 负责内容 |
|---|---|
| scripts/prepare-dsh-runtime.py | 从固定归档准备私有资源，核验归档/包身份，不执行npm；首次显式record信任表，普通准备或verify不改锁 |
| config/dsh-runtime-lock.json | 固定官方来源、17个依赖身份及285个第三方文件完整SHA256表 |
| Core dsh_runtime.rs | 编译期信任表与宿主源码、完整资源集合/摘要、有界读取及父运行取消核验；返回既有HostPaths |
| scripts/lib/dsh-runtime.ps1 | 复用同一准备脚本的只读verify模式，解析结构化核验结果 |

| dsh_runtime_probe example | 同一真实生产宿主加载完整SDK、执行96，在自己的完整副本中验证身份破坏及预取消；不构造模型 |

## 真实工程验证与边界

准备实际官方归档后，通过生产Rust/Node宿主describe与execute，计算15 + 27 * sqrt(9)实际返回96。工程探针11097毫秒完成：SDK真实字节翻转、额外真实文件、SDK实际文件缺失均拒绝；恢复后重新核验通过；父运行预取消返回dsh_runtime_interrupted。只修改探针自己的TempDir完整副本，关闭后确认目录不存在；正式资源、插件来源及用户配置未修改。

复制探针从package-all.ps1解析并调用原来的Copy-PackageResource及依赖函数，使用真实manifest资源项、真实资源排除规则和核验器，没有复制实现或替换SDK。源/目标均保持290文件及93908058字节，目标逐文件核验通过。此探针只证明真实复制函数的资源接线，不替代完整六发布门、MSI安装或正式页面实操。

PowerShell辅助首次执行发现Get-Command返回多个Python应用，拼成无效可执行路径，调用失败；改为只选择首个明确Application后核验及manifest检查通过。没有使用其它Python自动重试伪造成功。

## 开发/打包与下一步

先在已审查来源上执行python scripts/prepare-dsh-runtime.py，再走原package-all发布流程。该脚本仅写仓库tmp私有暂存，已存在的输出只读核验，不覆盖。如果宿主源码更新导致旧暂存不符，应保留原失败并重新准备专用暂存资源，不能把旧锁删掉或改成允许全局兜底。config运行时锁、SDK锁、准备/核验脚本已登记build_inputs；实际复制产物继续进入payload摘要。

下一步接线仍按既定P3方案：市场固定来源解析/工程绑定操作、默认停用安装按钮、真实describe启用并持久化快照、FrozenParentContext绑定工具定义、原provider调用ID与共享预算执行、停用/卸载撤资格与取消收尾。完成后再生成正式安装包，用真实qwen3.8-flash测试市场全流程。当前固定运行时和复制工程结果不能替代上述页面与模型验收，完整Paint及Browser按下至释放关闭竞争仍开放。
