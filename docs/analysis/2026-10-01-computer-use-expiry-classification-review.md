# 输入许可到期与取消分类修复

057真实Qwen绘画CF首次规划102991ms，预算内开始笔画后 helper 明确报 `stroke_cancelled: permit expired`。057将所有stroke_cancelled归为cancelled，控制器遂把确定期限到期显示为取消；真实回执仍正确保留3点、partial及released。不能据此推断用户点了中止，也不能据鼠标释放推断闭合路径完成。

修复只在核心统一分类器增加DeadlineExceeded，匹配明确的permit expired文本，不把旧“已取消或超时”或等待许可失败猜成期限到期。Web搬运原始原因并保持回执与有界收尾事实；现有控制器、最终落库入口按deadline_exceeded转为timed_out。释放未确认继续优先mouse_release_failed并不可重试；到期同样不自动重试。没有改模型、思考层级、许可有效期、共享预算或绘画完成条件。

风险：错误文本是当前helper契约，必须保持精确匹配；未来helper协议若改名需一起更新。没有回填057历史失败记录。核心和Web离线build及既有分类回归通过；新增一项回执回归覆盖到期且已释放/释放未知两种实际后果，9项相关Web检查通过。058已正常出包、安装退出0、唯一版本和10个关键产物核验通过。真实Qwen的单闭合眼睛CI成功；补画CJ在视觉验证阶段stage_timeout，不是笔画许可到期，不能由此认领新的真实期限到期现场通过。详见[058正式回归报告](../testing/release-0.2.58/change-report-and-targeted-test-plan.md)。

另一个问题是CF选点落在矩形外，以及规划耗时很长。其证据已与分类问题分开记录。现有规划器保留完整当前截图/观察，并继承原模型medium配置；本轮不降低思考层级、延长预算或删除视觉验证来制造成功。后续若调整内部规划上下文，应单独说明职责与实测收益，不能未经真实请求核验宣称慢因完全已归属模型。
