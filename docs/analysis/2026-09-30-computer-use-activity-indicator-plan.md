# Windows CU 活动泛光与 Paint 联合验收方案

日期：2026-09-30。新增需求来自用户：模型调用 compute use 时在整个 Windows 四周泛光，顶部显示 **Coolzhu Agent is using your computer**。先按现有架构设计、审查，再实施；与真实 Qwen Paint 绘画一起验收。当前主会话独立实施，不使用子代理。

## 当前架构与最小接线

Web `computer_use_executor.rs` 已负责父运行核对、输入隔离、权限、跨进程桌面输入所有权、适配器构建、控制器运行及收尾。Tauri桌面壳负责原生窗口，已有透明/不可聚焦窗口和独立认证宿主心跳。沿用这些职责，不在聊天前端推断运行状态，不新增输入执行器、审批或恢复系统。

新增独立 `computer_use_activity` 只持有当前进程的真实活动租约。执行器完成接纳、互锁和适配器准备之后取得租约；不从数据库历史状态、模型文字、ToolUse意图、浏览器快照或缓存结果生成活动信号。租约只由作用域收尾释放，取消请求本身不提前宣称物理输入停止。

独立只读活动路由复用宿主认证，返回active和短展示租约，最多1KiB；不发送提示词、模型回复、截图、输入参数或密钥。复用桌面宿主传输轮询，活动状态与浏览器资源登记相互独立。后台异常/网络失败/展示租约超时撤除光效；撤除只意味着失去活动确认，不证明输入已释放，未知释放仍走既有隔离与恢复。

Tauri新增独立 `computer_use_indicator`：每个实际显示器一个透明、无边框、无任务栏、不可聚焦、鼠标穿透的展示窗口。先隐藏建立、成功设置穿透、按实际物理屏幕边界定位后才显示。四边使用玉石青绿柔光，顶部文字只在主屏显示。不提供表单、按键、外链或网页可调用IPC；窗口标签不加入现有capability白名单。不改变Paint或其它目标窗口焦点。

## 生命周期

1. 0真实派发、输入隔离拒绝、输入所有权争抢失败、适配器未准备、缓存回执：不建立活动租约。
2. 具备动作能力的真实控制器进入运行：发布租约，桌面宿主显示。覆盖该次执行内的观察、模型规划、输入和验证，避免每个鼠标动作单独闪烁。全部动作能力关闭的原生只读适配器不建立活动租约。
3. 正常结束/控制器返回：释放活动租约；宿主下一次刷新撤除。
4. 取消：沿用现有执行取消及清理，作用域返回/Drop后撤销；光效不作为取消已收敛证据。
5. 后台崩溃、认证失败或通信中断：宿主独立短时限兜底隐藏；原有安全库恢复职责不变。
6. 显示器热插拔/位置/DPI变化：从宿主读取实际monitor边界，撤除失效窗口并重布局。渲染失败不得显示会拦截输入的普通窗口。

## 实施与审核

既有技术审核会话已收到方案并返回实际回复，认可“真实CU执行链→活动租约→认证活动信号→独立提示层”。审核重点是创建时机、取消不代表停止、租约失效不代表释放、焦点/命中、多显示器DPI和无IPC。

主会话采纳上述边界；活动模块只负责显示事实，不持有权限决策。显示失败不通过网页报调试细节，不使用人工点亮演示替代模型验收。实现后完成离线build和必要生命周期边界检查，再打包/正常入口实操。

## Paint 联合验收（全部实际操作与截图）

| 项目 | 通过标准 |
| --- | --- |
| 真调用 | qwen3.8-flash当前轮有结构化CU登记、实际输入所有权及执行回执，不能复用历史blocked |
| 泛光 | 执行过程中Windows四边泛光可见；主屏顶部准确显示指定文字，底层Paint仍可见 |

| 不误报 | 0调用、门禁拒绝和历史回执轮不泛光；后台异常后不永久残留 |
| 显示环境 | 当前屏幕DPI实测正确；多显示器未实测时明确列为待测，不能凭布局代码宣称通过 |

## 当前实施状态与交接

已按上述方案接入源码。Web新增独立 `computer_use_activity.rs`，执行器在适配器准备后的当前调用栈建立作用域租约；独立认证GET只返回active/lease_ms，租约上限1800ms、响应上限1024字节。宿主扣除完整请求往返耗时，150ms看门狗撤除失效显示；取消后等执行作用域返回才释放，不据取消请求判断物理输入停止。

桌面新增独立 `computer_use_indicator.rs`，每个显示器一个物理坐标透明窗口；主屏静态页面有准确指定文字，其它屏仅边光。初始化隐藏、不可聚焦、无任务栏，穿透设置成功后才显示；不在capability白名单，不提供调试UI。只加载打包资源协议的两个固定页面，避免开发入口的devUrl误加载HTTP控制台。

工程结果：Web及Tauri离线build通过；Web完整并行检查 **1270通过、0失败、2忽略（36.09秒）**，Tauri **59通过、0失败（2.17秒）**，模块接线 **8通过（2.66秒）**。新增生命周期检查覆盖正常Drop、异常展开、过期和未认证读取，不能代替桌面实操。审核实录见 [回复](../testing/release-0.2.32/installed-followup/activity-indicator-review-dom.txt) 与 [截图](../testing/release-0.2.32/installed-followup/07-activity-indicator-review.jpg)。

当前正式0.2.32输入资源仍isolated，待人工复核2条，Paint画布空白。新功能尚未安装/实操通过，不能计入既有验收。计划随后随正常发布链出候选包，再由真实Qwen与Paint共同验收；不从测试接口人工点亮泛光冒充通过。多显示器/DPI、焦点、鼠标命中、实际取消均待实操。测试者不自动放行或清安全库；微信不改不测，Devin暂缓。
