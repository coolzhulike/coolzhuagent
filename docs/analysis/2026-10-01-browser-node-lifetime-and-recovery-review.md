# 044实测后的节点有效期与审批记录修复方案

2026-10-01，主会话审查及实施；用户暂停Pro复审，继续执行。不使用子代理，不更换真实Qwen。

## 真实失败依据

正式044已核验安装，AK只处理本轮当前URL，没有续做历史AI/AJ。原生观察成功，初始目标验证16.235秒、规划6.903秒，随后输入预检返回`native_browser_node_expired`；步骤回执`not_sent / not_needed`，页面仍为0。宿主观察引用固定有效20秒，短于该次正常的验证加规划总耗时。这是Agent接口有效期与实际请求链路不匹配，不能算模型绘制或滚动能力失败。

另正常恢复首次仅关闭旧阻断，审批的运行清单为空；后端只读取最近一条决定，抹掉更早逐条接受的两个遗留运行，输入重新隔离。通过第二次正常桌面原生确认恢复safe；保留事故、许可及决定历史，未直接改运行库。

## 选择与责任边界

1. 宿主随机节点引用保留上限调整为120秒，覆盖默认120秒CU总预算内的验证和规划等待；引用仍不是授权。总任务deadline、当前父运行资格、资源/文档/导航身份、当前AX角色/名称、可交互状态、当前几何/命中和两次采样均独立重检。输入预检和一次性执行票据仍为2秒，不随引用缓存扩大；最多保留4份观察、每份最多128节点，动作后全部旧引用撤销。更慢的模型等待仍应安全拒绝，不无限续租、不把旧引用换成新随机引用或自动重放。
2. 人工风险接受投影累计同一scope的所有已落库决定、去重排序。仅接受决定明确列出的既有运行，不接受未来运行，不关闭未声明阻断，不改变Unknown许可或原生确认。最近决定仍单独提供展示；空清单不表示撤销旧决定，当前没有显式撤销契约。
3. 不新增Agent循环、数据库schema或权限系统，不改provider/思考程度。复用既有cache、store及回归用例；安装版真实Qwen仍是功能验收标准。

## 定向回验

- 既有节点测试增加模拟25秒规划等待，引用仍可解析；到期、异文档/房间、未知节点及动作后撤销仍拒绝。Shell离线build与必要测试。
- 既有人工决定测试扩展空清单不撤销、去重、不同scope不串，以及未声明阻断不被接受。Web离线build和完整既有回归。
- 工程回归与正式CU实操不能同时占用物理输入范围。本轮首次完整回归1281通过/9失败/2忽略，其中`input_owner_busy`、恢复协调Busy等与AK实操重叠；原日志保留，空闲重跑不能覆盖原失败记录。
- 下一正式包核验安装后，重复当前普通长页单次Scroll，必须观察实际位置变化及单次步骤回执；其次只读cap0、正常重启不误隔离，再推进Type/Nav。Paint后续独立联合验收，不继承旧截图通过。
