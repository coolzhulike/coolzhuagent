# 子 Agent 与插件安装补充审查

审查时间：2026-09-27。主会话核查源码后，与 ChatGPT 会话“整合审查执行计划”共同审查。该审查是设计依据，不代表实现或验收通过。

## S2.5 子 Agent

审查轮次：`da3ab7ad-c9d2-4085-b66e-9a954bd4c85d`。

发现：tool-registry 的 Agent 工具仍通过独立线程创建旧 ConversationRuntime，默认模型硬编码，没有完整继承宿主模型配置、父运行取消和根预算。普通聊天、CLI 和工具测试通过，不能代替此项完成。

实施边界：

- registry 负责请求解析与角色工具约束；显式注入 HostAgentRunner，不引入全局可变 runner。
- 宿主创建子执行身份，绑定父 run/tool call、工作区、会话和聊天室，以及模型、权限、预算快照。
- 默认继承父模型配置；显式覆盖只能选择已有且允许的配置，不能以裸模型名创建未知 provider。
- 子权限取父权限、角色约束、请求工具的交集；预算不超过父剩余额度，共享取消和截止时间。
- 子执行复用模型、工具、usage、轨迹服务，不重新获取父聊天室的 ChatTurnGuard，不偷偷新建或切换 UI 聊天室。
- 父取消后不发起新模型请求、工具或桌面输入。默认不允许父结束后留下隐式后台子任务。
- 无宿主 runner 时明确未执行，不能回退到旧默认模型运行。

验收：真实子任务成功、权限收窄、父取消传播、预算耗尽、配置覆盖拒绝、usage/trace 归属，以及无宿主时的明确失败。仅禁用旧入口属于保护措施，不能标记 S2.5 完成。

## NAV-06 插件安装

审查轮次：`5984cf0a-765a-4af6-b346-3cc6ff741c42`。

发现：PluginManager install/update 先删除已有目录再复制，安装末尾默认启用。复制或元数据写入失败可能破坏旧安装，不能直接挂接 Web 安装按钮。

实施边界：

- 复用 PluginManager、registry 和 settings，不另建插件运行时或权限系统。
- 在同卷 staging 完成复制、清单及包校验后切换目录；切换前保留旧版本。
- 使用轻量操作记录，明确目录、registry、enabled state 的提交阶段与恢复结果；不得声称多文件天然原子。
- 安装默认禁用，启用单独显式操作；更新保留原启用状态。CLI 若需要兼容快捷启用，使用显式选项。
- 失败返回真实失败；恢复失败必须报告待恢复，不把半完成状态当安装成功。
- 可信市场目录需要来源、版本、hash、大小、兼容性和权限信息；当前缺少可信远端目录，界面应明确未配置。发现本地插件不等于已安装，也不等于完整市场可用。

验收：复制失败保留旧版本、registry/state 写入失败、更新失败恢复、安装默认禁用、中断后恢复以及无市场来源的真实提示。

实现增量：Sol Max 已将事务实现拆入 `plugin-system/src/install_transaction.rs`，外部 install/update 和内置插件自动刷新共用该流程；回滚期间保留 backup，修正回滚中断后无法重复恢复的问题。插件库 37/37、命令路由 20/20 通过，插件库与 CLI 离线 build 通过；详见 [实施日志](../work-logs/2026-09-27-plugin-install-transaction.md)。这不等于 Web 安装接口或远端市场已接通，后者仍需单独实现与界面验收。
