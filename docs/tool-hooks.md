# 控制台工具前后置脚本

控制台支持在模型工具派发前后运行宿主配置的脚本。脚本是任意命令，具有宿主用户权限；目标工具的授权不会自动授予脚本执行权限。默认不运行任何脚本。

启动服务前由操作者设置 `COOLZHU_TOOL_HOOKS_CONFIG` 为配置文件绝对路径。文件格式：

```json
{
  "version": 1,
  "workspace_root": "D:\\my-project",
  "hooks": {
    "PreToolUse": ["明确审核过的前置命令"],
    "PostToolUse": ["明确审核过的后置命令"]
  }
}
```

独立授权通过启动进程的环境变量提供：`COOLZHU_TOOL_HOOKS_PRE_SHA256` 和 `COOLZHU_TOOL_HOOKS_POST_SHA256` 分别对应前置和后置事件，其值必须是该配置文件原始字节的完整 SHA256。只配置文件但未提供对应授权时，该事件的脚本不运行；摘要不匹配、配置错误或工作区不匹配时服务启动失败。不要把授权变量放进模型可修改的项目启动文件。

配置在启动时读取并冻结，运行中修改文件不生效；变更需重新核对摘要并重启。授权仅对配置指定的工作区有效，切换工程不会继承。单文件最多64KiB，每个事件最多16条命令，每条最多8KiB。

脚本从标准输入读取 JSON，并可读取 `HOOK_EVENT`、`HOOK_TOOL_NAME`、`HOOK_TOOL_INPUT`、`HOOK_TOOL_IS_ERROR`；后置另有 `HOOK_TOOL_OUTPUT`。前置先运行，目标仍经过原有工具权限重判；目标产生回执后才运行后置。退出码2拒绝执行，其他非零退出按既有规则记警告。后置失败不撤销已发生的目标效果，不能自动重试目标。

脚本受本轮预算与取消控制。重复调用、宿主权限拒绝和已停止轮次在脚本执行之前拦截。本接口不从工作区配置、模型参数或网页请求自动签发授权。
