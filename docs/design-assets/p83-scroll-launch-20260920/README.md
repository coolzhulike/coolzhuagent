# P8.3 卷轴山河开机动画

启动窗口先由中央向两侧展开金镶玉山河卷轴，再由同一位单手持剑的武侠桌宠从左到右逐字写出 `COOLZHU`。字形固定在各自槽位，玉绿粗笔芯和金色龙纹随动作显现；收尾仅保留七字，不留人物。

- [完整预览](preview.mp4)
- [终帧效果](final-1440.png)
- [卷轴背景生成提示与参考图角色](scroll-shanhe-v1-prompt.md)

运行素材在 `modules/gui-desktop/packages/tauri-shell/ui/assets/p83-coolzhu/`：35 张整人动作帧、6 张字形图（两个 O 共用字形）和 1 张卷轴背景。页面、播放器、字位与时间轴配置位于同级 `ui/` 目录。历史生成候选图未进入运行包。

基础验收覆盖 1440×900 和 900×520、逐字时间轴、跳过、Esc、减少动效、正常收尾，以及背景缺图时继续播放的纯色降级；字形或人物必需素材缺失仍报告资源错误。
