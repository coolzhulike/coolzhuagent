# 品牌头像资产记录

八张角色均实际使用内置 `image_gen` 生成，不使用脚本画角色。用户已选择大头萌系并授权仅做透明杂点清理、统一边距和尺寸导出。此选择不等于逐张成稿确认，也不等于正式软件验收。

- 正式可复用主图：`modules/gui-web/packages/web-console/assets/avatars/brand-v1/{generic,deepseek,chatgpt,qwen,claude,gemini,grok,glm}.png`，512×512、RGBA。
- 对应实际尺寸图：同目录 `32/`、`48/`、`64/`，共 24 张。
- `review-sheet.png`：八张成稿联图、浅玉石/深竹林底和真实 32/48/64px 小图。
- `provenance.json`：逐图原始生成文件、原始 SHA256、成品 SHA256、alpha 边界和清理方法。
- `generation-prompts.json`：内置工具所用最终提示词与参考关系。
- 候选与运行 manifest 已在本隔离工作区更新；主入口仍由总控按 `2026-10-10-brand-avatar-entry.patch` 串行集成。禁止只拿 manifest 而遗漏 JS 路径白名单与静态资源接线。

DeepSeek 鲸鱼娘是社区二创方向，本次为重新生成的原创变体；ChatGPT 白龙娘是用户指定方向。千问、Claude、Gemini、Grok、GLM 和通用助手均为本项目的非官方拟人设计。未宣称供应商官方角色或授权。

清理方法：以 alpha>32 的最大连通主体识别角色，保留其相邻两像素抗锯齿，删除主体外杂点；仅裁去主体外透明空间，将完整主体等比缩放到最大边410px，居中放入512px透明画布。主图全 alpha 边界至少51px（约10%）；缩放使用预乘 alpha，防止透明像素带来暗边。人物有效像素、配色与饰件不重画。低尺寸文件分别从同一主图导出。

图像原始生成文件保留在内置工具输出目录，没有删除。生成废稿（比例不一致、文字、背景或额外动物特征）未进入资产目录。

当前限制：未应用共享入口 patch；Rust 构建两次因 Windows 内存/虚拟内存不足失败，已交由总控协调串行构建。未运行正式软件、未做原生 UI 联合验收。头像成稿逐张取舍可继续迭代，不把本联图称为正式截图。
