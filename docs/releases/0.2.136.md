# CoolzhuAgent 0.2.136

本版汇集 0.2.127 之后的控制台、运行时、输入安全、启动与打包验收修复。保持预发布状态；机器级升级和真实多屏条件仍按各自证据验收。

## 主要变化

- 聊天室回复可定位对应运行记录，补齐历史同步、搜索迟到结果、用量归属和长结果分页/预览边界。
- 加强取消后的进程树回收、输入租约、权限撤销与冻结授权验证，保留拒绝和未知状态的真实回执。
- 补齐 Goal 失败重规划/重试、Hook 预算与配置、诊断全局配额/脱敏，以及附件暂存清理边界。
- 修复 LSP 路径规范化及导航结果过滤、启动器健康判定和资源配套问题。
- 启动画面改为 COOLZHU 字标下方静坐运气人物，移除开机朱印和舞剑；保持跳过、减少动态效果和失败退出行为。
- 构建捕获、源码身份和许可证证据随打包链校验，MSI 载荷与最终控制台逐项核对。

## 已完成的验证

复用本轮实际构建与验收收据，没有为了文档整理重跑已通过项：

- 10 个发布构建入口完成；构建前后的 586 个核对源码文件 SHA256 一致。本次公开提交准备时再次核对，无变更。
- 包目录 1,489 个载荷文件核验；433 个本次 Cargo 观察组件、20 个非 Cargo 组件有许可覆盖。
- MSI 解包后的控制台与 267 个许可相关文件字节核验通过。
- 原精简的 16 项关键验收完成；统一清单当前 29 项关键通过、5 项条件阻塞，1 项用户豁免不列入执行计划。不等同于全部扩大矩阵通过。
