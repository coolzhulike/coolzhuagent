# CoolzhuAgent 0.2.140

本版完成九项问题及相关需求修改，包含安装版验收中发现的工作区切换、回收站删除、订阅账号初始化和媒体协议修复。

## 主要变化

- 启动先显示动画，历史分页加载、增量保存，避免每次启动全量重写。使用最近成功打开的工程；同端口空闲实例经身份验证后正常退出并切换，实时连接不再阻止退出。
- 工程支持新建、移除最近记录及受保护的回收站删除。主聊天室权限状态可用；默认档外部目录逐次审批，完全访问二次确认、可撤销且重启失效。
- 定时、后台、轨迹和电脑操作集中到任务页；运行记录按约 12 小时窗口清理，保护活动任务及聊天引用。移除终端扩展入口，保留模型执行所需的 shell 能力。
- 模型设置统一保存会话与参数，API 和订阅分栏；首批订阅为 Devin、OpenAI / ChatGPT。目录返回精确模型 ID，避免生成不存在的思考档位。
- 头像库使用 Q 版 DeepSeek 鲸鱼娘系列；旧内置头像恢复随模型选择，自定义上传保留。窄面板按钮自动换行并保持在卡片内，字段提示及账号说明精简。
- 图像、视频独立配置参数与端点；Agnes Video 2.5 使用实际异步任务协议，产物保存为本地附件。媒体用量和对话 token 分开统计。
- 统计展示真实 token、缓存去重、首 token 时间及有完整时间事实的解码速率；未上报数据不显示为零。技能支持创建、安装和按会话启用；Superpowers 固定版本安装后默认禁用，插件安装保留来源及兼容校验。
