# CoolzhuAgent 0.2.143

本版在聊天室落地「任务清单」能力：模型可在多步任务中自主建立/更新/收尾清单，前端实时展示，Devin 会话的计划推送也并入同一份清单。另含上一轮 `/` 命令、代码图谱与气泡透明化的合并成果。

## 主要变化

- 聊天室 TodoWrite 由服务端接管执行（PR #102）：不再写工作区共享文件，改为 SQLite `chat_room_todos` 表按房间+会话隔离，含版本号、来源与更新时间；会话库 schema 29→30 自动迁移。**升级后无法用 0.2.142 及更早版本打开本版写过的会话库，发布说明需向用户标明此项不兼容。**
- 工具权限改为只读档，只读房间也能用；模型输入中不含任何存储路径；清单上限 30 项、单项 300 字符；子代理不再收到 TodoWrite，避免覆盖父会话清单。
- `/clear` 与删除聊天室时连清单一起清理；孤儿行在会话保存时一并回收；全部完成时行自动删除。
- 模型侧每次回包附带进度摘要与「连续完成 3+ 项但缺验证步骤」的提醒；当前清单快照注入请求 system 文本（不落消息）。
- 前端工具栏新增「任务清单」（PR #103）：常驻徽标显示完成/总数，弹层按会话分组渲染三态，SSE 事件驱动刷新不轮询；XSS 安全渲染。
- Devin ACP `sessionUpdate:"plan"` 映射进同一清单（PR #104）：整表替换、priority 保留、回放不写库、非法载荷降级为诊断不中断会话。
