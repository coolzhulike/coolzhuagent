## 范围与架构判断

已检查 Rust workspace、主要模块接口、Web Console 的路由/存储/调用链及前端宿主结构。架构梳理见 `docs/2026-09-19-architecture-review.md`。项目虽已拆分能力 crate，但模型循环、会话配置、权限、SQLite 与 UI 编排仍集中在 Web Console；本轮沿用现有右栏宿主，并将新参数页、聊天体验、统计接口拆为独立模块，避免再把新增逻辑全部堆入两个大文件。

本轮实施第一至第四优先级；第五优先级仅交付审阅清单与三张概念效果图，没有实施整体主题、美术和图标替换。

## 交付内容

### 第一优先级：工具暴露和恢复

- 完全访问权限与模型工具开关分离，调试构建默认开放权限，发布构建仍默认关闭；明确保存的配置继续生效。
- 会话工具开关、白名单、暴露模式及电脑操作策略进入请求与执行两端校验。
- 修复小上下文只保留电脑操作工具的策略；文件/命令任务不会因容量小而被迫走 UI。
- 收紧语义工具及旧本地分发旁路；纯文件语义不错误归入电脑操作失败熔断。
- 流式与非流式支持一次保留上下文的无工具恢复；文本伪调用不会被执行，也不静默作为成功答复；文档/代码示例不误判。
- 房间权限 API 区分保存权限与实际权限。调试开放时前端明确显示“调试完全访问”，不把“撤销房间授权”误称为关闭调试开放。

详细证据见 `2026-09-19-tool-policy-and-recovery-verification.md`。

### 第二优先级：统一模型会话参数

- 新增 `model_settings.js/css`，从一个页面配置会话、协议、自由模型 ID、地址、精确 Endpoint、密钥、上下文/输出容量、采样、思考模式/层级/预算、工具开关和白名单。
- 支持实际已实现的 OpenAI Chat Completions、Anthropic Messages；无需新增 Provider 表项才能填写新模型。
- 参数传入真实请求构建，兼容旧配置及旧容量接口；未知模型的显式思考配置不会仅停留在 UI。
- 密钥不回显，留空保留，清除需要明确选择；长本地模型路径不再受旧 64 字符上限截断。
- 参数页有输入即时草稿保护、保存回调等待和跨工程失效机制。编辑另一会话不会被普通列表刷新覆盖。

详细说明见 `2026-09-19-unified-model-settings.md`。

### 第三优先级：导航与环境

- 主界面只保留左快捷图标、中间聊天和右扩展栏；原展开聊天导航与拖动条不可再次恢复。
- Agent、工程、聊天室三个顶部入口为当前位置的下拉选择；调用实际激活/切换 API。
- 工程下拉支持近期路径和完整路径输入；房间下拉保留搜索、新建、重命名、删除。
- 环境切换串行化，运行中禁止切换；切换时保护发送入口，避免在错作用域提交。
- 头像与视觉 Agent 控件迁入右栏，头像单独保存，不再依赖隐藏的旧 Provider 表单。
- 修复旧 CSS 导致输入区占满父容器，以及低宽度时隐藏品牌/头像仍保留网格占位的问题。

### 第四优先级：消息、索引、耗时、用量

- 思考只在生成期间以临时区域显示；开始输出正文后收起，完成、失败、中止或切房间后清理。
- 工具请求/结果进入独立状态栏，支持展开摘要。覆盖 `tool-call`、`tool-summary`、`tool-result`、电脑工具与旧下划线别名；历史、搜索、索引、朗读遵守同一过滤原则。
- 新增完整房间历史搜索、消息序号、分页结果、定位高亮、载入目标前后上下文、返回最新记录。
- 新增逐轮计时与回复消息上的持久耗时；覆盖普通请求、流式、接力。
- 新增 SQLite 用量事实表与耗时表，独立于旧会话快照重写；流式快照取累计值，完成或取消只记录一次已返回用量。
- 右栏按当前聊天室汇总输入/输出、请求数、各 Agent 与缓存字段；不会将上下文估算当作消耗。旧历史、接口未返回和适配器未解析的细分不做回填估算。

新增后端模块 `src/chat_insights.rs`；新增路由 `/api/chat/rooms/{id}/search`、`/insights`；接口文档已更新。

## 浏览器实测

使用本地 Playwright CLI、Edge，在独立 `tmp/2026-09-19-e2e` 中运行控制台 18765 和模拟模型 18766。原安装版 8765 未替换，未对真实服务发送付费模型请求。

已实测：

1. 流式思考约 5 秒后切正文；无空助手气泡，完成思考隐藏。
2. 模型结构化 `read_file` 读取隔离文件；工具结果仅状态栏展示，正文保留用户与助手结果。
3. 普通一轮 usage 为输入 100 / 输出 20；含工具轮计入两次模型请求。三次请求累计 300 / 60，与模拟模型日志相符。
4. 刷新及重启测试服务后，耗时和用量仍在；完整索引不包含工具结果。
5. 搜索 `READ_FILE_OK` 仅命中最终回复；点击定位高亮。
6. 房间切换清空旧状态、旧历史结果和计时；工程往返切换后统一参数正确重载。
7. 实际权限 API 与页面均显示调试完全访问，保存的房间权限保持原值。
8. 1280×720、1024×600 布局检查；修复输入框高度、顶部占位，无横向页面溢出。另检查 1440×900。
9. 记录面板打开期间完成新一轮回复，搜索结果自动刷新；`流式验收完成` 从 1 条增至 2 条。
