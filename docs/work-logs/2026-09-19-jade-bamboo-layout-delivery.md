# 2026-09-19 玉石竹林布局实施记录

> 后续状态更新：同日已完成0.2.12 Release重新打包安装及安装后隔离验收。本文末尾“安装版未替换”为布局实施当时的状态，最终结果见[发布报告](../2026-09-19-release-0.2.12-change-and-test-report.md)。

## 用户确认的方向

用户允许修改布局，要求保留控件与图标的玉石色泽、武侠竹林背景图层，并提高字体与背景的对比。此轮直接实施该方向，复用已有美术资产。

## 实施

- 新增 `modules/gui-web/packages/web-console/src/wuxia_layout.css`，在其他样式之后加载，同时接入 Rust 内嵌静态资源。
- 顶栏改为横向环境选择，主区域保留左侧快捷图标、聊天和右侧扩展页；底部使用紧凑竹绿色状态栏。设置入口固定在快捷栏，去掉工程名称旁重复齿轮。
- 工具页只保留内部单层标题及返回/关闭，协作页保留协作/任务/状态/工具页签。顶栏三个入口仍分别打开环境选择下拉。
- 保留玉绿金线 SVG、玉石 PNG、人物头像和月夜竹林；降低水印和装饰干扰。消息正文为 15px / 1.75 行高，时间与辅助文字 12px，深绿色内容背板保证阅读稳定。
- 参数页使用深竹绿背景和玉石保存按钮；正常输入 14px，辅助文字最低 12px。按实际容器宽度切换单双列，低高度窗口中保存区随表单滚动。
- 工程操作按钮从 24px/10px 调整到 32px/12px，目录树随空间增长，窄栏上下分区；终端命令独占一行，超时/运行/清空并列，保留输出空间。
- 修复记忆页内容被压到零高度的问题，记忆内容排在维护作业/历史之前；列表、星图、详情与来源均可达。修复旧装饰伪元素占用卡片文字列及行高不足，卡片正文与删除按钮各占独立列。
- 视觉页截图前置，操作卡自然撑高，常用操作双列；浏览器代理/桥接诊断展开后进入正常文档流，不再被后续预览覆盖。
- 本轮没有改变模型请求、权限判断或工具执行语义。第一轮已经实现的搜索、消息定位、思考收起和用量统计继续保留。

## 验证

- `cargo test -p coolzhu-web-console --offline`：8 项库测试、1 项 helper 测试、944 项主程序测试全部通过，共 953 项。更新了将“设置”留在更多菜单、旧侧栏名称、重复齿轮等过时静态契约；保留真实入口和资源覆盖。
- `cargo build -p coolzhu-web-console --offline`：成功。最终产物 `target/debug/coolzhu-web-console.exe` 已包含新增 CSS。原有未使用代码等警告仍存在。
- 使用隔离运行目录与 18765 端口验证，未修改真实聊天室数据。浏览器在 1440×900、1280×720、1024×600 和 760×600 下检查；窄窗口沿用右侧覆盖式抽屉。
- 参数栏通过键盘调宽至约 608px，表单双列；调窄至 320px，表单单列且无横向溢出。返回、关闭与保存仍可达。
- 顶部 Agent/工程/聊天室下拉、设置/工程/终端/搜索/用量入口实际打开验证；搜索 `READ_FILE_OK_20260919` 得到 2 条匹配并能定位消息，统计显示隔离数据中的 6 次请求。
- 任务、记忆、视觉、浏览器页面由独立浏览器复核。没有触发截图采集、真实点击、命令运行、模型请求或配置保存；浏览器控制台无错误，保留原有 iframe sandbox 提示。
- 色值对比计算：消息正文 `#edf5ee` 对 `#102b21` 为 13.60:1，辅助字 `#b5cbbd` 为 8.81:1；参数正文/辅助字对 `#10271f` 为 14.27:1 / 9.79:1，保存按钮深字对渐变较暗端为 6.80:1。这里只报告主要配色组合，不代表逐像素检查所有装饰图层；消息背板为接近不透明的深色层。
