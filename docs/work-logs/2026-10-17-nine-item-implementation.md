## 实施口径与边界

- 最近工程以最后一次成功加载/切换为准；旧实例必须通过产品身份、同一用户和随机重启凭据验证，且无活动任务，才允许优雅退出。无法验证或运行中时保留原实例并报告原因，不按端口盲目终止进程。
- 磁盘删除限定为当前工程下、曾打开并登记过的子工程，使用 Windows 回收站，不降级为永久删除。删除其它目录前需切换到其父工程；有外置会话库时拒绝猜测数据归属。
- 完全访问授权按会话库与房间版本保存在进程内；数据库里的旧 full_access 值不会在新进程自动恢复授权。auto 按 D3 暂不实现。
- Devin 使用已有 ACP；OpenAI/ChatGPT 使用官方 Codex CLI 的 app-server 与账号 OAuth。后者没有被伪装为 ACP，当前接入限制为文本会话，未开放其原生工具、图片或 Goal 执行。账号/模型目录来自官方进程；不本地推算订阅余额。
- 运行类数据删除与聊天正文、token 事实分开。旧 ACP 回执删除前保留轻量用量事实；过期且空闲的远端绑定失效，下轮从保留的聊天历史重建。
- 新 CU 桌面截图保存到本次接纳的会话库所属目录。历史共享截图目录不能证明独占归属的文件保留，不扫描删除用户外部文件。
- `dev_open_permissions` 的兼容响应字段仍为 false；测试接缝保留，仅测试构建可用，生产没有启用分支。
- 本轮开始前工程已有大量修改，均保留；没有提交、推送、安装发布或替换正在运行的安装版。
