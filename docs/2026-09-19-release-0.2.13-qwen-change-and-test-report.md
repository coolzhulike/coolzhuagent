## 3. 本轮产品改动

### 3.1 每个会话独立决定图片处理方式

统一参数页新增“图片输入能力”三态，并保留既有“模型用途”：

| `parameters.supports_multimodal` | 生效行为 |
|---|---|
| true | 目标模型按选择的通信协议直接收到图片 content blocks |
| false | 系统默认视觉会话先描述图片，目标模型只收到描述文本和原用户问题 |
| null / 未设置 | 兼容旧配置，沿用原模型用途与能力推断 |

默认视觉路由读取实际保存的 `active_vision_session_id`，复用该会话的协议、地址、Endpoint 和密钥，不硬编码 Agnes 服务。视觉描述来自一次禁用工具的真实请求，标明来源和观察边界，作为附件资料传入，不升级为系统指令。视觉模型与目标模型用量分别入账。

统一处理普通工具对话、流式对话及截图理解入口。没有默认视觉模型、默认视觉被关闭图片能力、附件丢失、无效格式、预算删图、视觉返回空内容或工具调用等情况，均明确失败；不会静默跳过图片后模拟“已经看图”。

图片入口只接受当前附件目录的受控引用；支持 PNG/JPEG/GIF/WebP，最多 8 张，单张 20 MiB、合计 32 MiB。格式检查是文件签名检查，不能等同于完整像素解码验证。历史图片目前不会自动重传，视觉转述也未单独保存为可跨轮复用的记录。

### 3.2 协议适配

- Anthropic 原生接口将通用图片块转换为 `image/source`，覆盖普通与流式发送；不再直接发送 OpenAI 图片结构。
- Qwen3.8 的思考层级和开关映射为原生字段，并校验互斥参数和非法模式。
- Qwen3.8 思考模式的工具选择采用 auto，避免发送不受支持的强制指定工具选择。
- 默认视觉的屏幕描述调用也复用会话实际协议，不再固定走一种兼容接口。

完整契约、边界及本地 HTTP 请求体断言见 [多模态测试契约](testing/release-0.2.13/multimodal-test-contract.md) 和 [协议验收记录](testing/release-0.2.13/adapter-protocol-verification.md)。

主要代码：`web-console/src/main.rs`、新增 `multimodal_input.rs`、`model_settings.js`；`llm-adapter/src/reasoning.rs`、`request_parameters.rs`、`providers/openai_compat.rs`、`providers/claw_provider.rs`。完整相对路径和 SHA256 见 [source-fingerprints.json](testing/release-0.2.13/evidence/source-fingerprints.json)。

## 4. 测试方法与结果

真实调用使用独立运行目录和端口 18795，仅在本机复用用户授权的 qwen / Agnes 凭据，清空克隆历史。正式 8765 的已有聊天室没有被用来生成测试消息。测试 PNG 只包含三种图形及文字，文件名不泄露答案；所有源码修改与动画创作都是模型实际工具执行结果，验收者没有替模型修改最终 HTML。

| 测试 | 实测结果 | 耗时 |
|---|---|---:|
| 初次基础对话，17×23 | 正确返回 391 和指定标记 | 3.081 秒 |
| 初次图片直传 | 红三角、蓝圆、黄方形和 JADE-7382 全部正确 | 3.900 秒 |

### 4.2 五轮长程 SVG 文件任务

每轮延续同一会话和房间，工具只开放 read_file / write_file / edit_file / glob_search / grep_search。最初从空文件开始；每轮保留原始请求、SSE、回复、用量、运行终态和 HTML 快照。

| 轮次 | 任务 | 耗时 | API 请求增量 | 工具结果 |
|---|---|---:|---:|---:|
| R1 | 鹈鹕、自行车、腿脚和背景动画 | 185.463 秒 | 3 | 2 |
| R2 | 检查并修正相位、关节、脚踏关系 | 173.581 秒 | 10 | 9 |
| R3 | 暂停、0.5–2× 速度、恢复默认 | 94.234 秒 | 7 | 8 |
| R4 | 低高度布局、减少动态及系统偏好 | 134.231 秒 | 9 | 9 |
| R5 | 检查前四轮要求、闭合和最终标记 | 70.126 秒 | 7 | 7 |

合计约 **10 分 58 秒**，36 次模型请求、35 条实际工具结果，工具终态全部 completed。累计输入 1,330,000、输出 38,778 tokens；这是多次请求之和，不是单次上下文长度。部分请求会产生多个工具结果，两个计数无需相同。

R1 的“文件生成成功”没有被直接计为动画成功：独立浏览器发现 SVG 实际尺寸为 0、页面空白。R3 后已在模型自行迭代中修复。最终 R5 基础 7 项、扩展 12 项检查通过（部分检查重叠），包含画面运动、暂停像素静止、实际变速、恢复默认、1024×600 / 720×480 完整显示、手动减少动态、系统偏好初始及实时切换，无页面异常或外部资源请求。

实际测得 0.5× / 2× 的 SVG 时钟速率分别为 0.501415 / 2.005997 秒每秒，比值 4.000672。人工看图确认鹈鹕长喙和喉囊、双轮、车架和腿部清晰，背景及轮腿随时间变化。最终 HTML SHA256：`F13CB35D1FC089DBD4C629D9F6B1427E2C9C1074C6AA65B40E21A45820E97ADD`。

成品见 [pelican-r5.html](testing/release-0.2.13/evidence/pelican-r5.html)，浏览器报告见 [pelican-browser-review.md](testing/release-0.2.13/pelican-browser-review.md)。模型最后一轮明确只做源码检查；浏览器验证由独立验收完成。

### 4.3 Paint / Computer Use：失败已复现

宿主先准备一个新的空白画图窗口。这是测试准备，不计为模型启动应用。房间持久化 full-access，正式可用工具仅 `computer_use_perform`，禁止脚本产图、导入或粘贴图片。

| 轮次 | 目标 | 耗时 | 原生 CU 终态 | 输入 / 笔画 |

| R2 | 手绘粗略海绵宝宝 | 43.444 秒 | 同一错误稳定复现 | 0 / 0 |

根因与后续验收见 [Computer Use 问题报告](issues/2026-09-19-qwen-computer-use-test.md)。未进行第三次相同重试，也没有把静态图片生成算成手绘通过。

## 5. 未修问题及优先回归

本轮用户要求记录实测问题。下列缺陷已定位并留证据，**未包含在本次修复中**：

| 优先级 | 问题 | 后续最低验收标准 |
|---|---|---|
| P1 | planner 没有收到完整动作 JSON 结构，严格解析却要求嵌套对象 | 真实构造的请求包含 schema、动作清单和约束；合法 click 有输入证据，非法结构仍可解释拒绝 |
| P1 | 桌面正式工具无自由笔画/画布拖拽 | 真正按下→路径移动→释放，绑定新鲜窗口/截图，取消也释放，前后像素证明笔画 |
| P1 | 正式电脑 planner 无图片输入，verify 只看 UIA 文本 | 原图或受控视觉转述进入内部规划；不能以窗口文字变化认定绘图成功 |
| P1 | InputJsonDelta 混入思考 | 工具 JSON、HTML 和参数不再进入 reasoning；真实思考和工具内容分开保存 |
| P2 | 跨轮内部记录当普通 assistant Text 重放 | 正确恢复角色与工具/思考协议，避免重复、可控裁剪，重启后表现一致 |
| P2 | 工具开始状态遗漏、结果重复活动 | 同一调用按稳定 ID 聚合开始/完成，不把活动条数当工具次数 |
| P2 | 内部 planner 用量漏记、缺原始计划诊断 | 统一关联 room/turn/call 记录 usage；保存脱敏计划摘要和解析位置 |

真实长任务 R1 思考记录 33,864 字符，其中 12,925 字符是工具参数 JSON；7 条内部消息随后以 Text 进入 R2。详细证据和建议修复边界见 [真实任务问题报告](issues/2026-09-19-qwen-real-test-findings.md)。

其他未覆盖项：真实 Anthropic 云端视觉（仅本地协议测试）、所有图片类型和损坏像素解码、取消/超时竞态、混合多目标完整接力、历史图片自动复用、长时间动画录像及多浏览器兼容性。不要从本轮通过项目推断这些都已通过。
