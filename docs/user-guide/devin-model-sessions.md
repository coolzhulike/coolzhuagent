# Devin 模型会话使用方法

适用：包含此功能的 0.2.69 候选版本及后续版本。此处接入的是官方 Devin CLI 的 ACP 聊天会话，使用官方账号登录；不是 HTTP Provider，也不是插件页中独立的 Devin Cloud 任务 API。

## 配置入口

1. 安装官方 Devin 桌面应用或 CLI。Windows 桌面应用捆绑的 CLI 可自动发现，无需填写 Base URL 或 API Key。
2. 在 coolzhuagent 左侧点击“更多”，打开“插件市场”，展开“Devin 聊天室 · 模型与会话设置”。也可在“设置”页选择通信协议“Devin · 账号登录”。
3. 点击登录入口，按官方网页完成本人账号授权。登录只关联账号，不会创建模型任务。授权后刷新状态。
4. 点击“获取远程模型”。目录来自当前账号的 `devin models list --format json`，包括目录提供的各家族、变体和费用说明。只显示当前账号实际返回的 ID，不由名称猜测模型，也不限制为 SWE 免费模型。
5. 选择模型候选并采用。若该家族的真实目录提供标准思考档位，可在“思考层级”选择；选择档位时，模型 ID 同步切换到目录中实际存在的对应变体。不会拼接不存在的模型 ID。
6. 填写会话名称并保存。温度、Top P、上下文和输出限制等使用 Devin 默认值，页面不会提交不受支持的 HTTP 参数。切换模型后重新核对思考档位。
7. 回到聊天室，在顶部“发送对象”勾选已保存的 Devin 会话；需要分离上下文时新建聊天室，再发送消息。在插件页保存配置本身不会改变发送对象。

## opus-5.5 high

登录后在真实目录中查找 Opus 5.5；仅在账号返回对应 High 变体时选择并保存。不能用手填 `opus-5.5-high` 代替目录和 ACP 核验。发送提示前还会通过 ACP 配置响应核对精确生效 ID，缺少模型、换模失败或实际 ID 不一致时停止，不静默切换 SWE 或其它模型。

## 当前能力边界

聊天室文本流复用 coolzhuagent 的宿主上下文组装、聊天记录、记忆选择、停止和运行台账。配置保存不代表实际模型调用通过；以账号目录、ACP 生效模型和真实完整回复为准。

此版本正式聊天入口尚未开放 Devin 的宿主 SKILL、插件工具、Browser Use、Computer Use、附件、Goal 或子 Agent。代码中的 MCP 桥原型不能当作已接通的能力。纯文本审查需要在消息中提供经过筛选的源码与事实，不能声称模型自行读过整个工程。

CLI 固定版本目前为 `devin 3000.10.48 (fcf7ba39)`。版本改变或出现未适配的目录/配置格式时，会提示重新验证，不生成模拟模型目录。企业账号也可能限制可见模型。

官方模型说明：[Devin CLI Models](https://docs.devin.ai/cli/models)。官网家族别名会随服务更新，精确可用变体以登录账号的实时目录为准。
