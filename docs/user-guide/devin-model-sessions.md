# Devin 模型会话使用方法

适用：包含此功能的 0.2.69 候选版本及后续版本。此处接入的是官方 Devin CLI 的 ACP 聊天会话，使用官方账号登录；不是 HTTP Provider，也不是插件页中独立的 Devin Cloud 任务 API。

## 配置入口

1. 安装官方 Devin 桌面应用或 CLI。Windows 桌面应用捆绑的 CLI 可自动发现，无需填写 Base URL 或 API Key。
2. 在 coolzhuagent 左侧点击“更多”，打开“插件市场”，展开“Devin 聊天室 · 模型与会话设置”。也可在“设置”页选择通信协议“Devin · 账号登录”。
3. 点击登录入口，按官方网页完成本人账号授权。登录只关联账号，不会创建模型任务。授权后刷新状态。
4. 点击“获取远程模型”。目录来自当前账号的 `devin models list --format json`，包括目录提供的各家族、变体和费用说明。只显示当前账号实际返回的 ID，不由名称猜测模型，也不限制为 SWE 免费模型。
5. 选择模型候选并采用。若该家族的真实目录提供标准思考档位，可在“思考层级”选择；选择档位时，模型 ID 同步切换到目录中实际存在的对应变体。不会拼接不存在的模型 ID。
6. 填写会话名称并保存。温度、Top P、上下文和输出限制等使用 Devin 默认值，页面不会提交不受支持的 HTTP 参数。切换模型后重新核对思考档位。
7. 回到聊天室，在顶部“发送对象”勾选已保存的 Devin 会话；需要分离上下文时新建聊天室，再发送消息。在插件页保存配置本身不会改变发送对象。

## opus-5.5 high

登录后在真实目录中查找 Opus 5.5；仅在账号返回对应 High 变体时选择并保存。不能用手填 `opus-5.5-high` 代替目录和 ACP 核验。发送提示前还会通过 ACP 配置响应核对精确生效 ID，缺少模型、换模失败或实际 ID 不一致时停止，不静默切换 SWE 或其它模型。

## 当前能力边界

聊天室文本流复用 coolzhuagent 的宿主上下文组装、聊天记录、记忆选择、停止和运行台账。配置保存不代表实际模型调用通过；以账号目录、ACP 生效模型和真实完整回复为准。

0.2.69 初版只提供文本会话。加入工程只读审查增强的版本，在 Devin 连接设置中提供“允许读取当前工程用于仓库审查”复选框。勾选、保存，并在聊天室选择该会话后，模型可以通过宿主 MCP 调用 `read_file`、`glob_search`、`grep_search`，范围限于当前工程。大文件可分段读取；宿主仍负责权限、取消、预算和工具台账。不开启时维持文本会话。

当前只读审查已经用 `claude-opus-5-5-high` 真实验证：模型通过宿主工具读取 Cargo.toml，宿主有完成台账和精确生效模型回执。这不表示已逐字审查所有文件。完整仓库审查必须记录实际覆盖范围。

2026-10-05 开发候选增加“允许 Computer Use”复选框。保存配置，在聊天室选择该会话，并由用户为该聊天室授予“完全访问”后，可使用宿主 `computer_use_perform`；内部规划和验收沿用同一精确模型，图片按 ACP 协议发送，不静默切到其它模型。指定应用内页面时，请明确写“当前右栏原生浏览器”“右栏网页”或“右栏表单”；仅写 browser 会按既有规则选择外部浏览器扩展。输入框操作通常包含聚焦与输入两个动作，任务动作预算应容纳这两步。

长程工具可能先返回 `status=running` 和本轮专属 `job_id`。模型应调用 `computer_use_wait` 等待同一句柄，直到收到实际最终回执；等待不会创建第二个输入任务，不应再次提交 `computer_use_perform`。每次等待最多25秒以适配客户端请求时限，执行总时限仍受原CU预算及聊天根预算约束。停止聊天、退出桥或房间权限被撤销后不能继续派发动作。`running`、输入已发送、鼠标已释放均不等于目标完成。

使用右栏 Browser Use 前，应先显示控制台，并从“更多 → 浏览器”打开网页，等待载入。当前原生页面支持点击、普通文本输入、顶层滚动、明确 HTTP(S) 地址导航，以及单个 `home/end/tab/enter/escape` 页面按键。按键先点击普通控件聚焦，再使用最新观察的控件引用；不自动抢焦点，不运行任意网页脚本或发送系统快捷键。下拉选择可通过聚焦后的 Home/End 和 Enter 完成，勾选和提交可使用真实点击。菜单展开、选择暂定、确认及提交是不同动作，预算需容纳完整流程。此处不宣称原生语义 select/check、标签管理、历史导航、拖动、iframe 或 shadow-document 已接通。

真实 `swe-2-medium` 已通过聊天室文本回复，以及右栏单击、文本输入、滚动、导航、只读和有步骤指导的完整表单验收；记录及截图见[真实验收报告](../testing/devin-acp/swe2-browser-paint-20261005.md)。完整 Paint 绘图和正式安装版仍在验收；此开发候选能力不能算作旧安装包已具备。宿主 SKILL、插件工具、普通聊天附件、Goal 和子 Agent 不在本次 ACP 桥的开放范围内。Computer Use 的观察图片支持不等于普通聊天附件链路已接通。

保存其它参数会保留已配置的较窄只读工具清单。只读工具不修改源码；应用仍在 `.coolzhu` 下写入正常运行台账和检索溢出结果。

每轮由宿主提供聊天历史和选定记忆，再创建新的远端 ACP 会话，避免远端加载历史后再次收到宿主全量历史。未确认收尾的旧执行仍不能启动下一轮。

CLI 固定版本目前为 `devin 3000.10.48 (fcf7ba39)`。版本改变或出现未适配的目录/配置格式时，会提示重新验证，不生成模拟模型目录。企业账号也可能限制可见模型。

官方模型说明：[Devin CLI Models](https://docs.devin.ai/cli/models)。官网家族别名会随服务更新，精确可用变体以登录账号的实时目录为准。
