## 本轮源代码复核与最小修复

`browser_panel::input_resource` 原先只检查PanelReply的active/hidden/loading/destroyed字段。主控制台隐藏到托盘时，页面可能继续驻留；旧面板字段不能证明主窗口仍可见。因此补入实际主窗口visible/minimized检查，查询失败、主窗口不存在、隐藏或最小化均不登记资源。该检查也由现有原生观察派发前与回调后复用；不要求窗口获得焦点，不因为其它窗口遮挡就猜测授权变化。

后台原先把未登记宿主和宿主已连接但无可用页面都报告同一个错误。本轮区分 `native_browser_host_unavailable`、`native_browser_panel_unavailable`，租约过期继续视为资源变化。对应说明通过现有工具错误与轨迹显示，不新增前端调试面板、公开登记查询接口或网页IPC；不记录令牌、URL正文或聊天室配置。

这是资源边界及失败定位修复，尚未证明N轮的唯一根因，也不是已经打通Browser Use输入。此前M暴露的输入前回执/UIA时效修复仍在同一后续分支，037包不包含这些新修改。
