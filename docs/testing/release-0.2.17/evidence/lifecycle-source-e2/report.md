## DATA-01：迁移、备份与前向拒绝

先通过产品 HTTP 创建两个新会话，加上种子会话共 3 个；在自建聊天室发送含中文的消息并上传一个中文文件名附件。SQLite 记录 2 条该房间消息、1 条带附件元数据消息和 1 个 `completed` runtime run。再从该隔离库制作**结构准确的 v26 样本**：移除 v27 才有的 `tool_calls` 两列并设 `user_version=26`；另将其中一个合成 `api_key_ref` 改成明确的旧版假明文，以观察旧配置迁移。它是人工退阶夹具，**不是实际旧 MSI 原样生成的库**。

用上述 exe 重新启动时，产品生成了 1 个 v26→v27 迁移前 SQLite 备份，备份 `quick_check=ok`、SHA256 `65FA8F60A321C08674CA2617B905394FF4B0FF4691888B6E751B52F3ADC71B54`。升级后 `user_version=27`、`quick_check=ok`，3 个会话名称、原聊天室的 2 条中文消息、1 条附件消息和 1 个已完成运行均保留，v27 两列存在。直接从该备份复制到第三个隔离目录并启动，也恢复了相同语义。早期构建曾把自建房间 2 条消息额外回填到 `main-room`；本轮修正后没有新增镜像。回填仅凭所有聊天室的稳定消息 ID 判断，保留同文不同 ID/时间/附件的历史，且不主动清理已有疑似重复记录。

假明文字节在**迁移前备份**中存在，这是忠实复制旧库的结果；升级后的活动 SQLite、兼容 JSON 与配置原始字节扫描均未出现该标记，逻辑 `api_key_ref` 为 `dpapi:v1:` 引用。测试结束时未留下活动 WAL 文件，因此不能把本次扫描扩展为所有运行中 WAL、已删除页或跨设备解密均安全。备份位于同一 `.coolzhu/schema-backups/` 下；本机样本备份文件、目录与活动库 ACL 同为 SYSTEM、Administrators、当前用户完全控制，未扩大访问主体。打包资源排除规则覆盖 `.coolzhu`、`backups*` 和 SQLite 文件；源码窄查未见诊断或导出自动包含它。备份原件未删除或清洗。现有同用户 DPAPI 往返有定向 E1 测试；换设备恢复仍需重新提供秘密，本次 E2 不作跨设备成功结论。

前向版本反例在**无未检查点 WAL/SHM 的干净克隆库**上测试：设 `user_version=99` 后启动被明确拒绝；数据库原文件 SHA256 前后完全一致，WAL/SHM 前后都不存在。修复是所有会话库入口先做只读版本预检，再由写连接在切 WAL 前复核。两个前向版本定向测试各 1/1 通过，其中一个同时核验原始数据库字节未变；`schema_upgrade` 的未检查点历史备份、失败回滚注入测试 1/1 通过。对于存在 hot journal 或无法无损读出的异常库，只读预检可能拒绝自动启动，须保留现场人工恢复；本轮没有证明这种异常库绝对字节不变。

## JOB-01：单次领取与中断重启

在独立工作区经 HTTP 创建计划，以本地假 OpenAI 服务作为可数的外部副作用。第一个计划触发后假模型实际收到 1 次请求，HTTP 返回 `executed`，`scheduled_job_attempts` 同一 occurrence 为 `settled` 且保存结果。第二个计划在假模型已收到请求、领取库记为 `running` 且结果为空时终止**仅隔离 18770 服务**。重启并再次通过 `/api/task-schedules/run-due` 触发，返回 `unknown`，解释为“已领取（running），可能仍在运行或中断，未重复调用模型或工具”；假模型总接收数仍为 2，未出现第三次调用。任务配置保留 `scheduled`，领取记录保留 `running`，需人工核对后决定下一步。

这证明该现场阻止了静默重复派发并在触发接口呈现未知状态，**不证明自动恢复完成，也不证明外部副作用恰好发生一次**。HTTP 中断窗口的客户端得到 `ConnectionResetError`，与服务被终止一致。原构建右栏把该任务显示为“1 项待执行”，卡片没有领取状态，[失败截图](job-unknown-before.png)；修复后列表用一次只读查询投影当前工程、任务、触发时刻的领取事实，右栏显示“0 项可执行 · 1 项待核对”和“本次触发已领取，执行中或中断后结果未知，未重复执行”，[复验截图](job-unknown-after.png)及[只读状态快照](job-list-projection.json)。这不改配置中的 `scheduled` 或领取库的 `running`，也不自动重派；执行库读取失败会显示“执行状态暂不可用”。精确 occurrence、无库不创建的定向测试 1/1，通过构建及实际浏览器点击验证。
