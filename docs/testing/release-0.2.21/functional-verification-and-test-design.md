## 相对 0.2.20 的变化

### 语言服务启动使用真实工程路径

触发：正常切换工程、打开 Rust 文件、点击启动。020 前端把用于草稿和布局的 `activeWorkspaceKey` 提交为 `expected_workspace`。该键经过 URL 编码并截断为 180 字符，后端与真实工程路径比较后返回 409；刷新无法修复。

021 从本次捕获的 `projectRequestScope().workspace` 取真实路径。布局键继续用于检测迟到响应，同时核对工程代次、Agent、房间、文件及启动序号。未取消后端工程比对，也未修改房间授权、全局权限或可信 Rust 程序检查。具体接线在 `modules/gui-web/packages/web-console/src/app.js` 的 `startLspPreview`；既有后端仍在 `lsp_host.rs`。

源码验证执行实际前端提交函数，空格路径、中文路径、会因旧存储键规则截断的长路径及缺失工程四场景通过。它证明请求体取值，**不等于真实长路径文件系统或原生 Rust 服务已通过**。之前直接 HTTP 场景没有覆盖这个前端错误，不能再用其成功替代完整 UI 链。

### 用户选择的动画 B

复用独立播放器、manifest 与桥接，不另建启动框架。保留玉轴山水和原字标；四姿态 V2 由单张透明图的独立裁样矩形、鞋底锚点绘制，保留原比例。姿态切换只画一帧，解决旧版交叉淡化的双头重影；人物在 2.40–2.78 秒独立退出，之后为字标/朱印定势。首次演出 4.6 秒，日常 980 毫秒，恢复不重播。演出完成和服务 ready 仍是两个条件。

主要文件为桌面 UI 的 `scroll-startup-player.js`、`coolzhu-seven-letter-manifest.js`、对应 actor 素材及播放器契约。它是四姿态合成，不能称为骨骼或完整逐帧动画。

### 卷轴工作区与阅读面

`scroll_theme.css` 接入透明卷框素材，仅绘制四边；中心不覆盖聊天、设置或右栏。正常边缘左右 30px、上下 12px，低高度收窄为 8px/6px。装饰不接指针、不进入键盘顺序，不新增原生浏览器祖先的变换或滤镜。正文实际 16px/27.2px，辅助 13px、输入 15px、发送 14px；内部维持玉石控件与深墨绿阅读面，竹林位于外围。

保留既有五入口、更多四项、底部更新、三顶层横向下拉及按需右栏，不恢复左侧展开聊天树。

## 失败与总体边界

020 的 LSP 原生 409 保留为前版失败，不追认通过。此前 019 的终端、文件草稿和浏览器折叠证据保留原版本。Paint 因既有输入安全隔离仍未实际画线，不能归因成模型能力或标记通过；也不借本轮测试自动放行历史事故。真实微信、混合 DPI/跨设备、远端插件安装、非 stdio MCP 与完整自动下载安装更新分别保留未交付或未验证范围。

本轮 Pro 补审已实际送达并收到两轮回复，认可局部方案且无新增设计阻断；见 [补审记录](../../analysis/2026-09-27-visual-lsp-candidate-review-request.md)。双方明确 shell 留白会改变内容盒，必须实测原生边界；切换后旧 LSP 应按归属失效清理，不将已合法启动描述为从未启动。此为基于所提供事实的窄审，不是“Pro 总体通过”。新 PR/CI 和所有待验行应在真正执行后更新，不能由测试数量或 MSI 构建成功合并判定四项任务完成。
