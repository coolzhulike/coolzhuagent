## 现场问题与边界

- 原临时源位于tmp，工程符号索引按既有约定排除tmp。为正常GUI打开另建工作区根目录lsp-098.rs，保留原源文件；根Cargo声明相应修改。这是自有无依赖Rust验收工程，不是替代模型的夹具。收尾按自有文件身份清理，不删除工作区或用户数据。
- 原文件拥有者清单曾按LF字符串计算SHA，但Windows文本落盘为CRLF；后续核对原内容的规范化行尾与初始SHA，再保存实际字节SHA。不是任意跳过不匹配文件。
- 新文件搜索只读旧files.json，需手动索引；深度优先目录预算又令大子目录后的根文件不显示。本轮已据此提交候选最小修补及回归，**不追认098包含修补**。
- 本轮不覆盖服务启动进行中工作区A→B→A、全部权限/并发矩阵、任意语言、全屏TUI或模型调用终端；总工作包保持部分完成。截图结合API和独立进程句柄事实，未把编译当实际验收。
