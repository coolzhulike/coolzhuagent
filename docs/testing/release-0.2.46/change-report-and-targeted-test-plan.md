## 针对性测试设计

1. 空白普通输入页：模型先点击标记字段，再输入本轮独有文本。截图应显示实际 input 事件回显；账本应有 click/TextInput 两个真实动作、正确投递与释放状态，终态目标达成。不得由测试者代模型填写。
2. 输入安全边界：未聚焦、焦点或选区变化、字段只读/禁用、原文变化、宿主或页面变化都应输入前拒绝；原值不得出现在模型投影和诊断中。错误不自动重放动作。
3. 明确地址导航：从 A 到 B；核对一次 Navigate、绑定 A 的动作回执、B 的目的地修订、最新 B 标题/正文和实际 URL。拒绝错误宿主/聊天室、关闭面板、未授权地址变化和危险 URL。
4. 基础回归：只读 cap0 不派发动作；单次滚动有实际 scrollY 变化；正常关闭页面后旧随机节点不得继续输入；取消后不产生新动作。
5. Paint：真实 Qwen 在实际画布拖动绘制闭合轮廓，再尝试简笔海绵宝宝；原图证明笔画、动作账本证明实际派发及释放，独立图像判定证明目标。泛光与顶部提示在真实输入期间出现，结束消失。直线或 L 形不能替代闭合/海绵宝宝验收。
