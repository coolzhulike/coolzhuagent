## 正常软件实操

从顶部工程目录→浏览当前工程文件→精确文件搜索，打开真实右栏编辑器。初读磁盘为A，原字节SHA在[初始读取及外部编辑事实](external-edit.json)中；编辑器保留未保存B，再以外部写入自有文件C。正常Ctrl+S触发“文件已被外部修改，是否放弃当前编辑并重新加载磁盘版本？”：[冲突提示实拍](conflict-prompt.jpg)。点击取消后编辑器仍是未保存B、未清空：[保留本地修改实拍](local-edit-retained.jpg)。独立磁盘摘要断言确认仍为C，旧内容没有覆盖磁盘；该断言所在首轮采证脚本后因事实形状比较失败，过程限制见下文。

不点击放弃或强制覆盖。收尾仅撤销本次自有未保存B至原A以清洁标签，不保存A，关闭标签和右栏、清除测试搜索；原已保留预览标签保持。[正式原聊天室收尾](formal-cleanup.jpg)。磁盘自有文件在最终SHA核验后清理，[清单](cleanup.json)。没有删除用户文件。
