## 快照方法与保管

升级前、安装后且未启动、首次启动并经界面切回原工程后，各保留一份一致性快照。应用关闭且 8765 无监听时，六个 SQLite 库用 SQLite online backup 合并当时可见的 WAL，逐库运行 `quick_check`；其余文件复制后逐一核哈希。三次快照共享一枚只保留在 `tmp/` 的随机 HMAC 密钥，公开结果只比较计数与带盐行摘要，不附真实聊天、附件、密钥、完整路径清单或原始库。私有备份位于 `tmp/candidate-0.2.18/upgrade-20260927-candidate-a/`，仓库 `.gitignore` 排除该目录；本机 ACL 仅 SYSTEM、Administrators 和当前用户有权访问。备份包含历史用户内容及可能的敏感凭据，恢复前应停止程序并核对同一 Windows 用户的 DPAPI 条件；本次未做恢复写入。
