# 终端输出可视修复：源码候选验证（2026-09-27）

0.2.18 安装版的终端 API 返回了命令和中文结果，页面辅助文本也包含它们，但[原始全窗口截图](installed-0.2.18/10-terminal-output.png)只显示 `>>` 和空白。其 ConPTY 响应中，最后一次回首页控制序列后依次有命令、中文结果、提示符、`>>`，后面约 23 行是擦除屏幕用的 `ESC[K\r\n`。旧页面把这些行追加成历史，又在每次 450 毫秒轮询（包括没有新输出）强制滚到底；右栏只容约 24 行，结果恰好被滚出视口。原安装失败证据保留，不追认修复。

本次只改 `src/app.js` 的终端文字投影与滚动：以有界的逐行字符缓冲处理跨批次控制序列和基本 CR/LF/CRLF、CSI H/K/J 重绘；擦屏填充不增长历史。空轮询不重写 DOM，画面变化时也只有用户原先贴近底部才跟随。没有改 ConPTY、权限、原始输出、后端 cursor、会话恢复或命令执行方式。

原始失败响应（保存在本轮私有 `tmp`）经新投影只有 5 行，命令、中文结果和提示符仍在。按 7 字符分成 147 批重放与整段一致；长输出后回首页重绘不遗留旧尾行；14 万字符无换行输出有界保留尾部；普通有意空行、单独 CR、CRLF 和用户上滚都经定向验证。`node --check`、`git diff --check` 与 `cargo build -p coolzhu-web-console --offline` 均通过。
