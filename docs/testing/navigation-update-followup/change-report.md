## 功能变更与测试边界

2026-09-27 安装后补修范围：终端清屏/滚动投影、工程下拉新增现有项目文件入口、原生浏览器随右栏折叠显隐，以及工程异步响应、标签草稿和写入请求的归属。工程误写已复现、修复并随 0.2.19 安装；设计依据及复现身份见 [工程归属补审](../../analysis/2026-09-27-project-response-scope-review.md)。

其他模型设计针对性测试时，工程归属应至少区分以下路径：

- 延迟旧目录、正文、差异或搜索响应，再切工程或换标签，旧成功、错误和加载状态均不能覆盖新视图。
- 两个工程存在同名文件，原工程有未保存草稿；切换后新工程必须读取自身文件，切回保留原草稿。页面刷新不是永久草稿恢复能力。
- 保存提交后继续编辑，迟到成功只确认提交快照，不得清除后续编辑；重命名/删除成功应更新真正执行所在工程的标签。
- 四个写接口缺少、空白或不匹配 `expected_workspace` 时零副作用；匹配时创建、保存、重命名和删除仍正常。旧 A 保存请求延迟到切 B 后，尤其 A/B 初始内容和 revision 相同时，也必须拒绝。
- 工程变化的 409 与内容 revision 冲突不同：前者不能自动重提交，不能弹出放弃草稿并加载新工程同名文件的确认流程。

这些判定是测试设计输入；执行结果须引用实际构建和截图/HTTP 记录，不能将清单存在当作测试通过。
