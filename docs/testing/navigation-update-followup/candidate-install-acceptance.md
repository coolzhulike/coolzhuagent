# 0.2.18 候选包安装与实操验收清单

日期：2026-09-27。本文是待执行清单，不是通过报告。与 [改动报告](change-report.md) 配套，供其他模型据此设计和执行针对性测试。

## 身份及现场

源码冻结后先完成组合构建与必要回归，再以显式版本 `0.2.18` 生成 MSI。记录源码快照、包报告 ID、载荷摘要、MSI SHA256、安装目录及安装后二进制摘要。开发构建的截图不能代替候选包截图；重编译后的哈希不能用于追认先前测试。

升级前对当前用户工作区做一致性备份和只读语义清单，记录会话、房间、消息、附件引用、模型参数和密钥引用、运行记录、定时任务、历史输入隔离记录。不要把真实密钥或完整私人聊天抄入报告。安装后对照这些项目，允许明确解释的迁移差异，禁止静默丢失、跨房间新增镜像或历史隔离被清空。

## 独立验证及未具备条件

CLI→Web→子 Agent、Goal 停止/执行权失效/工程固定、父子请求用量归属、MCP 标准 stdio 闭环在隔离工程执行，保存真实请求与工具反馈计数。它们不能靠界面截图证明全部语义，应与实际界面证据一起使用。

Paint 仍需实际操作者先完成既有输入资源的原生复核；测试人员不得代点确认、清记录或自动放行。真实微信缺 provider 联调条件时记录未验。新视觉资源等待用户选择；沿用当前资源的技术验收不等于新方案获批。GPT-6 Pro 后续已返回 DATA/JOB 补审，但最终总体审查仍待安装证据，不能用局部审查或主会话审查替名。

每个执行结果至少记录：构建/包身份、工作区类型、操作步骤、预期与实际、截图路径、相关运行 ID 或副作用、失败原因与复验结果。使用通过、失败、未执行三态；修复前失败记录保留，不只收集通过截图。
