# 长任务定时重排源码修补

run_due_task_schedules_once原先在扫描时取now，任务执行完成后仍用该旧值计算下一次触发点。例：120秒触发、周期60秒、310秒完成，旧逻辑把下轮排为180秒；下一扫描会立刻再次执行，与跳过积压周期的语义不符。跨日挂钟任务有同类问题。

执行与结果持久化完成后，以真实当前时间重排；原计划时刻仍作为周期锚点，示例改为360秒。独立advance_scheduled_task只负责计划重排，领取/权限/持久化职责保持在原模块；未改变任务投递目的地或创建新云会话。
