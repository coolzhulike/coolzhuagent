## 改动与模块职责

| 改动 | 所在模块 | 行为和边界 |
|---|---|---|
| 自然导航来源 | Web `native_browser_adapter` / `native_browser_verification` | 已结算输入后观察实际页面，可验证自然跳转及后续 Navigate/Click。保留新鲜资源、节点、工作区、房间和授权检查；先后标签不证明所有跳转的因果 |
| popup 排队 | Desktop `browser_panel` | 普通 popup 使用独立序号，不误增输入 revision；显式导航被覆盖仍撤销旧来源，旧队列不能在手动替换后执行 |
| SPA 地址显示 | Desktop `native_browser_source` / `browser_panel` | WebView2 SourceChanged 只同步同文档地址；精确显式 pending 才清加载状态，普通地址变化不提前开放观察；退役注销回调，不新增授权 |
| 输入意图识别 | Core `controller` / Web `computer_use_turn_scope` | 机械“输入”不误识别外发；“不点击目标页”不误当所有来源页都只读 |
| 绘图区观察 | Web `computer_use_desktop_bridge` / planner | 提供已有 UIA 绘图区候选；相对 points 仍针对原 target rect，visible_rect 仅供可见性核对，不另建专用画图引擎 |
| 多步新增验收 | 独立 `computer_use_visual_baseline` / planner | 首次可用原图在动作前固定。条件比较起始→当前，progress 比较上一步→当前；不存旧 UIA、不参与输入授权、不跨 job，不累计旧 met |
| ACP 图片传输 | `devin_acp/session` / `journal` | 仅合法 image session/prompt 出站 8MiB；普通帧、文本与入站继续 1MiB。提交前完整 JSON-RPC 和 write 共用规则，只记三项数字计数，不记图片/正文/密钥 |
| 错误分类 | planner | 分开供应商错误、接收通道结束和超时，不把实际 ApiError 吞成“任务无响应”，不回显任意 HTTP 原文 |

没有在正式前端增加调试卡片，没有改微信功能、清理安全库、放松权限或把历史失败重写成功。
