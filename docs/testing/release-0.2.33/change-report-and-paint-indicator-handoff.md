## 下一轮联合验收

1. 用户安装候选后，核正式目录版本/逐文件身份，并从正常启动器进入原工作区；不注入安全根、不覆盖Base URL/API_KEY。
2. 核现有安全复核状态。正式032最近仍isolated、两条待人工复核；测试者不代确认或清库。安全复核未完成时，只记录拒绝/不亮，不循环请求绘图。
3. 使用真实qwen3.8-flash指定CU入口，先辨认Paint画布和当前工具，选择画笔拖短线，不保存文件。只有本轮结构化工具登记、输入所有权/回执、实际线条一致才算动作通过；模型复述历史blocked不算。
4. 操作时同一轮原生截图拍到Windows四边泛光及主屏准确文字 **Coolzhu Agent is using your computer**；核Paint仍是目标前台、鼠标命中画布、指示层不接收输入。不以人工注入active或CSS演示替代。
5. 正常结束与现有取消入口分别核撤除，物理输入释放另依据原执行回执；租约过期或隐藏不代表输入已释放。补零派发、门禁拒绝不亮以及认证/通信异常后不永久残留。
6. 实际DPI/当前屏幕必测，多屏/热插拔未实测必须明确待测。后续再按原Browser Use计划完成正常启动的真实只读观察，之后渐进输入，不由泛光功能替代浏览器输入实现。
