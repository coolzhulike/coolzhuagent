# 0.2.39 变更报告与针对性验收

2026-10-01。主会话独立实现与测试。先闭环Browser Use，再Paint；本报告用于其它模型设计针对性用例，源码检查与真实软件验收分开记录。候选包生成后补充构建身份；未以工程检查宣称软件通过。

## 本轮改动

- `native_browser_verification.rs`：独立负责原生只读事实形状、精确URL、宿主只读标识及逐项验收结果校验。模型不能替换宿主标题/正文，不能凭不完整、重复或空证据结果宣称成功。
- `computer_use_planner.rs`：原生只读任务使用当前真实会话模型逐项判定，沿既有CU阶段预算、取消、诊断及统计链路执行。桌面视觉判定与Chrome本地验收保留原职责。
- `native_browser_adapter.rs`：只读标识来自接纳时冻结的本轮用户限制；不从网页或模型参数授予权限。仍无节点ID和输入接口，所有动作capability为false。
- `computer_use_turn_scope.rs`：识别“不得点击、滚动或输入”等完整组合只读限制；阻止续接历史Paint。
- 正式工具描述提示：browser任务包括内置右栏均只传URL，不能同时传application/window，减少Q轮目标类型冲突。运行时仍保留严格类型校验。

复用现有控制器与宿主观察broker，不建立新Agent循环、公开网页IPC或调试面板。不改Qwen模型、百炼地址、凭据及medium，不回退外部浏览器。038中的主窗口可见性、资源错误区分及输入前UIA确定未派发回执修复随包保留。
