# 全图标检查与修正报告

日期：2026-10-07。依据用户已批准的玉石细金边方案开展检查；本轮属于源码候选界面验证，尚未更新正式安装包。

## 发现的问题与修正

1. 二次生成的玉佩纹样与批准图不同，加上透明画布留白，缩小后与设计图差距明显。使用内置 ImageGen 参考批准原图重新生成按钮框、镂空玉佩、红灯笼，保留原始透明资源，使用 CSS 补偿按钮框留白，状态图等比显示。来源、提示词规格和实际边界见 `../../../modules/gui-web/packages/web-console/assets/ui-redesign/jade-controls-v3/README.md`。
2. 旧像素高光、部分图标自带立体底板、双色 SVG 和新皮肤混用。49 个功能 SVG 统一为 24×24 坐标、浅金主线/暖金辅线；原有简单图标保持功能轮廓，移除 11 个旧图标的立体底板，新增独立暂停图标。按钮承载唯一外框，移除图标自身第二层边框与像素化显示。
3. 定时任务等面板的旧主题选择器覆盖统一皮肤。对明确标记的纯图标按钮集中定义尺寸和皮肤；未扩大到文字选择器、状态徽记或页面业务逻辑。
4. SKILL/本地插件操作按钮纵向占位，预览标签关闭符号与其它控件不一致。操作区改为横向排列并允许换行；关闭按钮使用同一矢量符号，预览标签保留 20px 小控件与独立无障碍名称。
5. 统一按钮的 `display` 可能覆盖业务设置的 `hidden`。明确隐藏优先规则；保留禁用淡化、焦点轮廓、选中态和危险操作轮廓，避免皮肤抹掉状态含义。“暂停跟随”使用暂停符号，不再使用关闭符号。

- 安装包发布前还需在正式资源目录复核 49 个 SVG 和 3 个新 PNG 均被打入安装包，并截图确认正式安装版显示。正在运行时的发送→停止切换、审批动态态以及低高度窗口的最终安装验收仍需结合后续真实长程任务检查，不用简单夹具任务代替。

## 针对性回归指引

后续模型应按本报告和资源清单设计测试，重点检查：正式版静态资源完整性；顶部与输入区的对齐及纹样；各扩展栏是否仍被旧 CSS 覆盖；禁用与选中图标、权限徽记和焦点是否清楚；动态发送/停止与暂停/跟随切换是否保留正确功能名称；文件/网页标签关闭是否仅关闭所选标签。测试应保存实际软件截图，并将视觉通过与长程工具调用通过分别报告。
