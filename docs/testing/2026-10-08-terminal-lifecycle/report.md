# 右栏终端生命周期专项：真实ConPTY与界面恢复

阶段：0.2.97之后源码候选，尚未纳入正式安装版。主会话独立实施，没有模型请求、模型夹具、新Devin云会话或权限修改。沿用原SWE聊天室及工作区，只操作本轮创建的终端；Paint和微信不测。

## 发现并修复

1. 正式097的真实PowerShell字面量输入 `竹林𠮷😀` 只执行出 `竹林`。以ASCII构造补充平面字符可正常输出；在同一自有终端卸载PSReadLine后，字面量输入完整。根因为该行编辑器处理ConPTY补充平面输入，而非UTF-8管道损坏。现在仅在应用创建的手动PowerShell进程启动时卸载PSReadLine，不修改系统模块、全局配置或Devin登录进程。右栏本身已有命令输入框，仍保留真实shell、Ctrl+C和原生子程序控制台。
2. 前端只在初始化调用恢复，重新打开终端侧栏仍显示“终端尚未启动”，与后台真实active句柄不符。现在在侧栏打开时接入恢复；已经连接时保留增量输出，重叠的初始化/恢复不能覆盖新句柄。
3. 已退出终端的缓存超过一页时，原前端因closed=true停止读取，刷新只能显示第一页。现在退出后继续按cursor读取至空页；正常运行时保持原轮询节奏。
