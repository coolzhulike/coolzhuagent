## 已有真实实操结论

均使用登录后的swe-2-medium，无模型回复夹具。调试版中：单击、文本输入、滚动、导航、只读查询与聊天室回复通过；HTML表单按明确步骤完成click→End→Enter→勾选→提交，网页真实记录select=bicycle、check=true及submit={mode:bicycle,ready:true}，目标3/3通过。5步均确认发送和释放，11个内外层ACP尝试均end_turn并排空，完整回复在聊天室可见，耗时2分25秒。

Paint单笔输入通过；身体、双眼、笑嘴、衣裤和双手有真实笔迹。腿脚仍因模型视觉定位失败，不能称为完整海绵宝宝绘图通过。实际坐标落点与宿主映射相符，已有绘图接口可执行。按照用户“纯模型能力暂不处理”的要求，不扩大权限、不修改正确映射掩盖这一失败。多步取消、提示撤除和下一轮独立Paint输入通过；真实按下与释放之间的微区间取消竞争尚未覆盖。

截图、每个失败定位及真实执行回执见[完整实操报告](../devin-acp/swe2-browser-paint-20261005.md)与[证据目录](../devin-acp/evidence/20261005-swe2-cu/)。其中 `browser-swe2-form-07-pass.png` 是完整表单通过，`paint-swe2-legs-05-final-indicator-withdrawn.png` 是Paint真实失败终态，不可互换结论。
