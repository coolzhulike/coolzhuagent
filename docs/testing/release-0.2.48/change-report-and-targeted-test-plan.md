## 下一修正及针对性用例

代码检查发现原生观察刻意剔除了整个AX properties，规划器没有聚焦信息；上一步反馈也缺动作类型。后续包仅增加宿主确认的普通编辑节点聚焦索引与类型化动作种类，不传原值、选区或任意属性，不自动聚焦或自动填写，不改变验收标准及无进展阈值。聚焦只是准备动作，不能当作文字目标已达成。

后续测试模型可据此设计以下功能用例，全部实接原Qwen并附软件截图、父运行、CU步骤和终态，失败保留：

1. 初始未聚焦且为空的普通 text 输入框：模型一次点击后在新观察选择 text_input，页面实际回显本轮唯一文字；确认不同动作、最新引用、无网络提交。
2. textarea 及 search 框同一流程；密码、只读、禁用、shadow/iframe、选区或文档变更继续拒绝，不因为 focused 信息获得权限。
3. 聚焦索引缺失或多义时显示未知，不能据旧引用输入；记录的动作种类与宿主步骤一致，未知历史种类不进入反馈。
4. 明确源页导航到新页再次实测，检查新资源与观察；错误源 URL 继续拒绝，不能自动改成当前页。
5. 页面关闭、取消、环境切换与未确认输入不自动重放；电脑使用提示仅在真实活动时显示，结束后消失。
6. Browser Use闭环后继续Paint闭合路径、简笔海绵宝宝与全桌面泛光联合截图。DSH远程插件实际安装运行、四项整体审核仍未验收，PR74保持Draft。
