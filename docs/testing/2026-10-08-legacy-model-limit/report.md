# 旧容量接口：真实问题、候选修补与验收

正式113的旧model-limit接口没有应用当前本地服务容量：用户32768/1024、服务8192/4096时，统一配置页生效8192/1024，旧GET返回32768/1024。旧POST清零覆盖后返回1000000/65536，统一接口仍为8192/4096；采样0.25未丢失。完整响应见before113/facts.json。正式六路并发1352次读取/180次保存未捕获混合overridden样本，不把代码中的竞争风险表述成已复现。

候选GET在原会话锁内捕获参数/局部容量，并让DTO接收同一参数；POST沿用store→config顺序持锁保存，响应从此次发布配置构造，不重读其它写者版本。响应预算复用既有effective_model_limit_for_agent_snapshot，应用本地服务上限与用户更小预算，保留旧容量API只更新容量、保留其它采样/协议/工具参数的语义。无新全局锁、无std锁跨await，不增加时限或权限。

同一候选真实服务本地GET和清零POST两组均与统一接口相符，采样0.25保留；六路并发1309次读取/180次保存零混合样本。实际offline build0、完整Web1423通过/0失败/6既有忽略，lib8/native-host1通过，原始日志和退出回执已归档。第一次PowerShell5将cargo警告stderr当成异常而提前退出，属于驱动失败，build.ps1/build.log保留；随后用subprocess捕获实际子进程exitcode，未跳过编译或把失败改成成功。

独立正常旧POST保存32768/1024后，正常点击设置、滚动到预算区域，[原生截图](ui/budget.jpg)显示用户32768/1024、生效8192/1024和温度0.25。截图为正式113壳加载隔离候选后端，不能宣称113正式后台含修补。原始两接口响应见ui/facts.json。

三组独立工作区runtime_runs计数均0，模型请求0，没有模型回复夹具。qwen3.8-flash只用于参数规则配置，原SWE-2-medium/唯一island-kayak/revision51保持不变且解锁；原后台一直保留，只正常停/恢复相符自有壳。自有测试后台与壳均已清理。候选尚待新正式包复验；完整Service/outbox、跨进程和Browser严格时序仍开放。
