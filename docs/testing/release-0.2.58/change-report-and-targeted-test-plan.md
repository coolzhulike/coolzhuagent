## 改动与模块职责

本包包含057的浏览器展示清理：工程或聊天室切换由 workspace_panels 通知 native_browser_panel 关闭旧原生资源、清理旧重开目标，再由 app 清空地址、页面、状态及导航选择。同一聊天室普通关闭后仍可重开原网页；更换发送模型不等于更换工程或聊天室。未添加第二个执行入口、持久化表或浏览器状态机。057正式截图已覆盖同聊天室自动重开、跨聊天室和跨工程清空。

058新增输入许可到期分类修复。核心 input_stroke 将明确的 `stroke_cancelled: permit expired` 区分为 DeadlineExceeded；Web desktop bridge 搬运为 `deadline_exceeded`，保留部分路径、点数、投递和释放事实。现有控制器及落库入口已支持转为 timed_out。释放未确认仍优先 mouse_release_failed，不自动重试。旧的模糊“取消或超时”不猜成到期；057历史 cancelled 不回填。没有调整许可期限、共享120秒CU预算、模型、思考层级或视觉验收条件。

设计审查：[浏览器上下文清理](../../analysis/2026-10-01-browser-context-display-review.md)、[到期分类](../../analysis/2026-10-01-computer-use-expiry-classification-review.md)。本报告公开测试后果和证据，调试记录只留文档及轨迹，不新增正式界面调试栏。
