## 真实模型与实操条件

使用原qwen3.8-flash会话、medium、百炼Base URL及已保存密钥。不使用模型夹具，不手写输入安全库，不代画、不代签机器释放事实。真实模型由`/api/chat/send`进入当前聊天室正常父轮及工具链路；每个任务使用独立编号，失败即终止，该轮不得补发伪成功。

浏览器使用普通本地HTML，分别有可见次数、输入文字、滚动数值与导航标记；仅记录实际网页事件，页面不代发输入或模型响应。边界页面按下处理限定2秒，不重复此前8秒阻塞事故。事件时间、父轮/CU/step回执及原始软件截图联合核对；如果关闭时按键已释放，记录“未命中区间”，不能算竞争边界通过。
