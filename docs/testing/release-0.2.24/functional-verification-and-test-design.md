## 已知范围

本轮插件市场安装来源限当前工程本地候选，未接入远程插件市场。网页仍受外部站点登录和 DRM 等限制。微信实际连接若缺账号条件须单列未验。未完成安装实操前，不宣布四项任务总体完成，不发布正式版本。

主会话与实施代理在后续代码审查中确认导航边界缺陷：A 页面打开 B、B 通过 HTTP 重定向回 A 时，旧页面过滤逻辑可能把最终 A 的加载事件丢弃，导致地址栏和加载状态不收尾。0.2.24 的上述基础入口与真实 Qwen 结果不因此撤销，但浏览器完整验收未通过。已安排最小修复与下一候选验证；当前安装包仍为本页记录的 0.2.24，不能把源码修复当成已安装修复。
