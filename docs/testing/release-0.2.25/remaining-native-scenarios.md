## 浏览器增量

1. 在当前受控聊天室打开本地动态网页，输入唯一非空标记。分别通过返回、首页、设置暂离，再从更多进入浏览器。每步核对输入值和页面历史；不点击“打开”重新导航来代替恢复。
2. 打开顶栏聊天室弹层后取消，缩放窗口并恢复。输入值应保留，网页不能覆盖弹层。明确关闭浏览器后再打开，旧页面应清理；真正切聊天室也应清理。
3. 使用18766素材：A→back-to-a（302回A）、to-c（302到C）、slow后立即导航to-c。最终页面、地址栏及加载状态必须一致，迟到事件不能覆盖最后请求。
4. 通过target=_blank链接和window.open按钮打开C，观察是否仍在右栏及宿主窗口数量。控制台本身与同端口loopback别名必须被拒；18765/18766的普通网页仍可用。

## 定时任务与并发

只创建一个带唯一标记的受控任务，明确选中qwen目标和当前测试房。选单次任务且先设稍后时间，保存后离开重开核对内容、目标和时间；到时执行并核对真实模型回复、完成记录和统计。不点击会触发既有到期任务的全局执行按钮；不修改用户已有任务。

模型执行期间打开统计和设置，确认普通查询可响应，页面没有Failed to fetch。模型完成后确认无残留进行中状态。截图分别记录待执行、真实回复、完成记录和普通面板响应。

最后仅删除本轮任务，确保没有后续自动触发。现有列表只提供删除入口时，如实记录“删除停止后续调度”，不能伪称已验证暂停/恢复。若目标无法选择真实qwen，停止该场景并记录产品缺口，不能以其他模型代替。

## 设置边界与终端

- 未保存一项可恢复的Qwen采样参数，切换发送对象后检查编辑对象、草稿提示及返回后的值。不能把其他模型值覆盖到Qwen；最后恢复原值，不发送给其他模型。
- 模型发现失败场景先勾选“此次查询不使用密钥”，只改尚未保存的地址为本机未监听端口；查询应明确失败并恢复按钮。随即恢复原地址和查询选项，不能保存这个测试地址，不能改密钥。正常查询仍应可用。
