## 复测依据

1. 新安装后先核验真实版本、二进制构建身份与候选报告；保留当前真实Qwen配置，不将安装成功等同于功能通过。

3. 对“本次”和“本轮”句首既有许可声明，普通绘画不应被误当作授权动作；安装、点击授权按钮、删除、支付、外发、输入密钥仍保留原审批要求。节点名或动作参数中的授权声明不可用来绕过核验。
4. Paint用当前新鲜截图选择真实白色画布的UIA引用或准确换算client坐标，禁止旧坐标与旧图认领。完整图需新增身体、两只眼睛、嘴、两条腿可辨认；输入已释放和图像发生变化分别记录，均不能替代图形验收。
5. 预算对照必须核查实际CU回执的`cu_budget_ms`，只改文件没有重载不能算有效对照。任何失败即结束该轮，后续独立测试须重新观察；不自动重放未知动作。
