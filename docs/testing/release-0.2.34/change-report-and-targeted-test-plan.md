# 0.2.34改动报告与针对性实操计划

日期：2026-09-30；当前主会话独立实现和审核，不使用子代理。候选用于修复正式033真实Qwen Paint暴露的规划超时，以及放行后误显示“待人工复核”。出包身份另行补充，本文件不宣称新版本已安装或Paint已通过。

## 问题、设计与职责

真实033根因与截图见 [安装实操报告](../release-0.2.33/installed-joint/installed-regression-and-paint-findings.md)。E轮模型规划23.858秒完成，agent固定20秒已结束等待，0输入。另一显示问题是API保留2条历史human_review_required记录，旧前端把它们继续当作当前人工待办，虽然当前资源safe且已允许输入。

预算修复限定在computer_use_planner：删除固定20秒截断，模型阶段直接沿用控制器建立的CU/根deadline剩余。规划前准备、默认视觉模型转述、诊断和请求客户端准备耗时连续扣减；不新增Provider配置、不修改Qwen模型/密钥/Base URL/思考层级，也不增加重试。当前CU总预算仍120秒，配置上限仍300秒；取消、500ms最小发起余量、迟到只记账/禁止动作沿用既有职责。目标是允许真实23.9秒响应在尚有整体余量时继续，而不是保证任意绘图都能完成。

显示修复限定在app.js与scroll_theme.css：当前未放行阻断/未接受遗留运行形成待复核数量；资源safe、允许输入且没有当前待办时隐藏徽记。历史处置数在轨迹详情明确称为“历史人工复核记录”，不删记录、不自动接受。机器对账显示“恢复处理中”，资源不可读显示“状态未知”，未知不等于无待办。

人工恢复返回、打开轨迹、聊天运行结束都会重读资源事实；刷新序号拒绝旧响应覆盖新状态。需要复核时金色高对比徽记、数量与轻微泛光，真正工具审批面板增强边框和文字对比；减弱动态系统设置关闭动画。点击“查看轨迹”本身不会替用户批准未决事项。

主会话架构审视：等待变长始终受原CU/根期限约束，阶段不重置时钟；只有当前真实请求可形成动作，晚回不补发；显示模块只读状态，不持有恢复决策。本轮没有取得新的GPT6 Pro审查回复，不虚报共同审查完成。沿用此前关于真实活动租约、取消与输入释放分离的实际审核结论。
