## 改动与判定边界

- 微信辅助进程独立封装：真实HTTP provider配置完整时由Web生命周期托管；默认不启动mock。显式外部服务URL沿用外部连接，不由本应用启停。默认端口冲突、未配置、启动失败与退出分别返回可读错误，只回收持有的子进程。
- 托管服务健康响应核对本次随机实例标识、网关地址、版本和provider类型；不使用远端返回的展示名称作为身份。旧外部协议缺类型时显示服务未确认，不伪报真实在线。
- 微信状态、扫码提示和管理员状态采用实时健康信息；历史online记录不代表当前在线，服务未确认时不继续显示旧二维码。未验证真实扫码或消息收发。
- 浏览器新窗口导航增加环境、视图代际及请求版本核对和错误反馈；前后退、刷新、停止可取消旧排队弹窗请求。普通地址导航沿用原重定向处理。
- `target=_blank`在025右栏未进入目标页的根因尚未证实；Wry回调投递不能保证发生在WebView2新窗口延迟处理完成之后。**NAV02503仍未关闭**，本补丁只确认加入状态防护，不能声称已修复该原生故障。
