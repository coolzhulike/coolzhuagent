# 0.2.75 改动报告与针对性测试交接

日期：2026-10-06。范围：Devin ACP 普通聊天室的同一远端上下文续接，以及实际发送对象的工具归属。SWE-2 与 Opus 5.5 High 均已用安装版完成真实页面验收。本报告不代表原整合计划的全部功能完成。

## 用户可见行为与使用方法

1. 在同一工程、同一聊天室中，选择原 Devin 模型会话配置继续发送即可。每轮恢复原远端会话，正常关闭或后台重启后仍续接。SWE-2 与 Opus 分别保留自己的上下文，彼此不共用一个远端 ID。
2. 模型配置保持 `swe-2-medium` 或 `claude-opus-5-5-high`，无需另填远端 ID；回复仍显示在本地聊天室。模型参数页说明续接规则，不在正式页面展示调试 ID 或游标。
3. 精确模型发生变化、或在设置中明确重置上下文时，会归档旧绑定并建立新的远端上下文。原聊天室消息不会因此清空。模型切换路径的完整真实回归仍待补充。
4. 远端会话无法恢复时，显示恢复失败，提示检查原登录账号或按需重置；不会悄悄另建会话、重发历史任务或改用 Qwen。
5. 本地新增或更正的历史、其他发送对象的新回复、系统说明与选定记忆变化，按增量导入。对远端已读旧内容的撤回是作废说明，不能保证从服务端物理擦除；完全清空需显式重置。

## 实现范围与职责

文件位于 `modules/gui-web/packages/web-console/src/`。

| 模块 | 修改及职责 | 验证重点 |
|---|---|---|
| `devin_acp/context.rs` | 新增消息 ID、内容摘要、撤回标记和实际回复归属的增量投影；SQLite 只保存同步摘要 | 已发送历史不重复导入；未发送的新正文不能误记为已同步；历史预算裁剪不等于删除 |
| `devin_acp/chat.rs` | 用冻结工程、聊天室、Agent 配置及调用通道确定稳定上下文；连接后登记增量 | 正常发送及重启使用原 `session/load`；每轮运行 ID 不再导致新远端会话 |
| `devin_acp/journal.rs` | 复用原发送状态机；稳定绑定仍核验旧轮取消、进程排空和工具收尾 | 只解除已确认收尾的锁，不把旧未知轮改判成功；CLI 版本变化仍需适配重新验收 |
| `devin_acp/session.rs` | 明确显示远端恢复失败且不回退新建 | 请求未发送与已发送后未知分开；保留原取消与失联语义 |
| `chat_run_admission.rs`、`devin_acp/bridge.rs` | 接纳时记录本轮实际目标；区分冻结父运行与实际发送对象 | 主会话为 SWE 而目标为 Opus 时可正常读文件；缺失、重复、跨运行或未接纳目标仍拒绝 |
| `main.rs` | 实际回复持久化后记录生成它的 Agent ID | 不按显示作者推断归属；失败结论在下一轮仍可作为宿主新增信息导入 |
| `model_settings.js` | 增加普通用户可理解的续接说明 | 不暴露调试字段 |

没有新增独立权限体系或第二套运行状态机。DSH/SKILL 完整桥接、Goal、Relay 与附件能力没有由普通聊天续接结果自动获得验收。

源码提交 665 的 push 检查通过，PR 检查出现两条既有协议测试的时序失败：3 秒期限可能在慢磁盘记账过程中耗尽，使待测提示尚未发送；80 毫秒外层取消与 300 毫秒模拟对端寿命也依赖调度。后续修改仅位于 `#[cfg(test)]`：明确确认对端收到 `session/prompt` 后丢弃 future，保留 unknown、取消、禁止再次派发等断言；失联测试增加实际提示方法断言并给握手记账独立余量。该补丁没有改变已安装 0.2.75 的生产行为，不能将后续测试提交冒称 MSI 的源码提交。最终检查结果在 PR 中按具体提交核对。

测试时序修补后再次真实离线 build 成功，协议 11 项通过；最终完整 Web 串行回归 **1390 通过、0 失败、6 跳过，91.79 秒**。见[检查收据](installed-context/local-validation.json)。原两条负向语义不变，仅消除毫秒调度依赖。

## 供其它模型设计针对性用例的边界

| 场景 | 应观察的接口或事实 | 通过标准／目前状态 |
|---|---|---|
| 同工程、同聊天室、同配置连续及重启 | 页面回复、绑定、context delta、ACP 终态和归属 | 已按上述六轮通过；不得只凭正确文本判断 |
| 主会话 SWE、目标 Opus | 接纳目标事件、工具桥、实际文件结果 | 候选实际 `read_file` 已通过；非主目标深层 CU 仍待实测 |
| 显式重置 | 旧绑定归档、新远端 ID、原聊天室记录保留 | 候选 SWE 已通过；原远端历史不当作新远端已有上下文 |
| 精确模型变化 | requested/effective、绑定归档及新远端 | 完整真实模型切换验收待补，不允许静默替换精确模型 |
| 远端过期或登录账号变化 | load 错误、未发送、未创建替代、未重复执行 | 待真实环境测试；不得伪造账号过期回包作为功能验收 |
| prepared/submitted 时异常退出 | 旧 attempt、进程与工具收尾、安全状态 | 崩溃恢复待补；未知结果不改为成功，不能绕过输入释放事实 |
| 其他模型消息、撤回、预算外更正 | 消息 ID/摘要、作废记录、实际导入次数 | 外部回复与两条撤回已候选通过；预算外更正新正文稍后被选中的完整流程待补 |
| 系统说明、记忆变化与撤回 | 替代说明、选定记忆、实际模型理解 | 实现已接入，完整记忆用户流程待验收 |
| 多发送对象任一失败 | 实际回复归属、宿主失败结论回送 | 保守跳过该轮归属可能多导入成功回复，不能吞失败结论；需补真实混合终态 |
| Goal、Relay、附件、DSH/SKILL | 各自真实业务入口和工具事实 | 未由本轮普通聊天结果闭环 |
