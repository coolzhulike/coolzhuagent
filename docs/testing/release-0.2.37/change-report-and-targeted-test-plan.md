## 变更

具体证据、技术依据、风险见[方案](../../analysis/2026-09-30-controlled-stroke-corner-loss-plan.md)。纯坐标边界先确认编译失败再补实现；该检查不驱动鼠标、不用于替代软件验收。相关离线build退出0，computer-use-core完整140通过/0失败（61.40秒）。正常发布链及真模型结果待补。
