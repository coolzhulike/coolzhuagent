# 0.2.68 Browser Use / Computer Use 定向修复与验收

## 本轮实测发现

0.2.67新独立只读任务使用日常表述“不点击、不输入、不滚动”，运行时没有识别全部禁止输入，按交互任务返回verification_failed；实际零输入。新独立界面取消任务通过正常聊天输入及停止按钮发起：父轮interrupted、CU cancelled、零输入、页面次数保持1；这覆盖规划期间UI取消，不替代先前已通过的按下至释放区间正式API取消。

独立Paint实例保留旧未保存画作，新建白画布并只保存准备文件CU067-fresh-canvas.png用于唯一窗口寻址；主会话仅准备黑色铅笔，未代画。原Qwen medium自行规划一条连续笔画；输入前stale_observation、not_sent、not_needed，CU最终budget_exhausted（一次尝试预算），完整画作未通过。模型规划期间窗口发生变化，拒绝旧观察是正确行为，不能把父轮completed写成绘画完成。

聚焦实现另有明确缺陷：无条件ShowWindow(SW_RESTORE)取消最大化，影响布局、画布几何与顶部提示。修复限定为IsIconic时恢复，保留既有前台验证、UIA与输入前身份/帧校验。

## 剩余验收

优先原只读失败复测及页面替换；输入按下至释放期间关闭与切换仍需要真实时序证据。Paint完整简化海绵宝宝、准确提示联合截图仍开放。每项记录真实父轮、CU、步骤、投递/释放、网页事件和原图；软件截图与机器事实一致才判通过。新候选尚未安装或未测试的项明确保留，不外推0.2.67结果。
