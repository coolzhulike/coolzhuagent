本报告保留出包前的候选事实与原失败。0.2.86现已正常安装，六项OOP编辑、单键、滚动与规划期间焦点/文档变化实操完成，正式身份与截图以[安装版交接](change-report-and-test-handoff.md)为准。本轮主会话独立实施/测试，真实模型SWE-2-medium，Opus暂停，微信保持原功能。所有真实验收均经正常聊天室，不用模型夹具替代。用户最新要求Paint不再复测，以下已有基本功能证据保留。

## 改动与职责

- OOP/跨进程子文档：固定DevTools调用跟随节点所属会话，编辑器解析、焦点/选区读取、对象释放不回退顶层。实际文字/按键仍由原WebView输入；滚动先核对目标局部命中，再经owner链映射，顶部/底部不转滚父页。
- Devin唯一上下文：当前聊天模型通过computer_use_respond回答宿主本次规划/验收；Exchange只交换请求回复，桥校验同job、request和父运行，原执行器继续负责输入、权限、证明及释放。内部规划不再session/new/load。
- Paint原图：MCP图像在固定CLI中没有实际到达模型，改为同ACP连接串行图片提示续轮。中间end_turn只让出生成，不结束父任务；同attempt、执行锁、模型与远端ID持续保留。能力、大小、总时限、取消与未知收尾沿用；不从terminal复活、不fallback新会话、不重发perform。
- 明确重绑入口：模型配置页面读取当前聊天室/Agent绑定，再以预期旧集合提交解除。旧绑定归档，本地聊天、失败和安全历史保留；运行中/未知状态或脏表单不能改绑。入口不创建云端，下一次正常发送才创建一次，后续恢复失败明确报错。
- 参数与显示：desktop drag仅points/duration_ms，宿主固定左键不作为模型参数。未知字段仍拒绝，不回显参数值。交接提示归为临时过程，不拼入最终答案。

## 复现与设计测试用例时应覆盖

同一聊天室选择SWE-2-medium并使用既有授权，先确认远端绑定；执行新任务后，再读取绑定和ACP台账，不能仅凭聊天自述断言唯一会话。重新绑定只用于用户明确清除旧远端的情形，不在每轮测试重置。

OOP输入使用127.0.0.1父页、localhost独立子页，记录可信input/submit/wheel事件。分别证明子输入、Enter、上下滚动及边界，父输入/提交/滚动恒零。计划期间的焦点、子导航与旧引用拒绝尚需补验，时序未命中不得追认。

Paint只需基础一笔折线：保留现有内容，在空白处绘制；核对新鲜UIA引用、真实投递/释放、原始前后图与逐项视觉判断。仅released/image_changed不足以通过。窗口歧义必须明确目标，禁止任取第一个窗口。模型看不到像素必须判失败，不把文字快照当图像证据。

取消/超时/连接丢弃后，不得恢复待执行动作或复用迟到回复；重绑不得释放未知attempt。正式安装后应再核实际版本、源码冻结身份和安装文件摘要，再走正常窗口入口实操，候选通过不等于正式通过。
