# B01 纯聊天/纯内容：3 组基线/候选配对

- 模型：`qwen3.8-flash`（provider `custom`，effort `auto`）
- room/session：每次新建空 room；session `session-1792519612697-22ffea3a2956ec99`
- 输入（固定）：`请只回答一个数字：2+2=？不要使用工具，不要先搜索或计划。`
- 执行方式：基线/候选各自独立端口、顺序执行；每轮新建 room，避免历史污染。
- 基线：从 HA-00 快照恢复后补齐缺失未跟踪依赖（低完整度重建），构建成功。
- 候选：当前工作区生产二进制。
