# 山水卷轴启动演出边界

生产页 `launch-performance.html` 加载 `scroll-startup-player.js`、素材清单和 `coolzhu-seven-letter-bridge.js`。旧逐字播放器已删除；素材仍保留，不删除历史美术源文件。

- 首次完整演出 4.6 秒：0–0.28 秒闭卷；0.28–1.25 秒同进度卷面与玉轴展开；1.05–2.32 秒Q版人物沉身蓄势、转腰进身、挥剑、落脚收势；1.55–2.50 秒整个原字形 logo 显现；2.50–3.35 秒定势；3.35–4.60 秒淡出交接。
- 日常启动 980 毫秒；恢复窗口应不创建启动页。宿主确实复用此页时也可传 `?mode=restore` 立即结束。
- `?mode=first` / `?mode=daily` 可用于实际桌面验收；默认通过本地 storage 判断首次/日常。storage 失败降级日常。
- Esc、跳过按钮、演出区域点击均可退出；减少动态效果模式不等待图像加载，120 毫秒结束。
- 图片加载 2 秒超时/失败立即结束；桥接最多 7 秒看门狗保护。完成、取消和失败只发一次 `launch-performance-complete`，保持 `consoleVisible:false`。此事件只代表演出结束，不代表后端服务 ready。
- 1680×900 画布等比 contain；既有空白卷轴山水背景与设计聊天参考同属墨绿/金龙/玉柱色系，并非同一张图。
- 原字形整体宽约 57.7%、中心高 48%；Q版人物采用五张完整姿态与鞋底锚点、重心轨迹合成，实际人物约 13% 高度。它不是骨骼动画。
- 朱印文字“酷朱”，放大为 126×144；低对比剑脊、竹叶、微雨辅助构图，不修改原字形。

运行边界验证：`node modules/gui-desktop/packages/tauri-shell/ui/tests/coolzhu-seven-letter-bridge.cjs`。自动检查不替代 ComputerUse 桌面截图：须检查闭卷、挥剑、整体 logo/朱印定势、退出后真实控制台，以及日常/减少动态效果/资源失败均能进入主程序。
