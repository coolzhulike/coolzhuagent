# 山水卷轴启动演出边界

生产页 `launch-performance.html` 加载 `scroll-startup-player.js`、素材清单和 `coolzhu-seven-letter-bridge.js`。旧逐字播放器已删除；素材仍保留，不删除历史美术源文件。

- 首次完整演出 7.8 秒：0–0.28 秒闭卷；0.28–1.40 秒卷面与玉轴展开；1.40–5.70 秒Q版人物蓄势、腾跃、出剑、回身收剑及退场；1.80–3.50 秒原字形 logo 显现；5.00–5.70 秒朱印显现；5.70–6.70 秒定势；6.70–7.80 秒淡出交接。
- 日常启动 6.5 秒，同一动作时间线等比例压缩，不再省略人物。恢复窗口不创建启动页；`?mode=restore` 仍立即结束。
- `?mode=first` / `?mode=daily` 可用于实际桌面验收；默认通过本地 storage 判断首次/日常。storage 失败降级日常。
- Esc、跳过按钮、演出区域点击均可退出；减少动态效果模式不等待图像加载，120 毫秒结束。
- 图片加载 2 秒超时/失败立即结束；桥接最多 11 秒看门狗保护。完成、取消和失败只发一次页面内 `launch-performance-complete`，保持 `consoleVisible:false`。原生交接通过演出页专用 `report_startup_performance` 命令完成；宿主校验调用 WebView 与资源 URL，并把开始、素材就绪、首帧、结束原因和交接结果写入既有诊断日志。命令失败时 15 秒宿主兜底仍显示主控制台。完成事件只代表演出结束，不代表后端服务 ready。
- 首帧诊断表示 Canvas 已执行绘制回调，并记录宿主接报时演出窗口是否可见；画面是否真正出现在屏幕上仍须用原生连续截图核验。
- 绘制帧失败立即以 `resource-error` 收尾；减少动态模式的同步绘制失败也停止播放器。退出时即使画布清理抛错，仍隐藏演出、保留错误诊断并只通知宿主一次，不因清理失败打断交接。
- 1680×900 画布等比 contain；既有空白卷轴山水背景与设计聊天参考同属墨绿/金龙/玉柱色系，并非同一张图。
- 原字形整体宽约 57.7%、中心高 48%；Q版人物采用四个从同一透明图中按各自实际边界裁样的完整姿态。每帧保留源图长宽比，以独立鞋底锚点和连续重心轨迹合成，约 170–230 像素高（1680×900 画布的约 19–26%，随姿态变化），动作切换时只画一帧，无交叉叠头。它不是骨骼动画；中文宽度/动态骨骼插值均不在此演出范围。
- 朱印文字“酷朱”，放大为 126×144；低对比剑脊、竹叶、微雨辅助构图，不修改原字形。

运行边界验证：`node modules/gui-desktop/packages/tauri-shell/ui/tests/coolzhu-seven-letter-bridge.cjs`。自动检查不替代连续播放和原生桌面验收：须检查单帧动作无双头、人物退场后仅保留字标/朱印、退出后真实控制台，以及日常/减少动态效果/资源失败均能进入主程序。日常模式不能再以没有人物的短暂停留作为通过证据。
